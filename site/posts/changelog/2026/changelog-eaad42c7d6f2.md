## 速读

The Changelog 2026 年 3 月 10 日当周的新闻速递（约 5 分钟）：OpenAI 周四发布 GPT-5.4，Augment Code 称它「第一个为 agent 工作流而生」的模型；Cortical Labs 用培养皿里的神经元玩起 Doom；Detail.dev 用几小时深度扫描代码库找严重 bug；主持人还自嘲「曾是 10x 工程师，如今没用」。开场主持人顺带提及地缘政治新闻（伊朗轰炸 AWS 数据中心）作为「重头新闻」，仅一句带过、未展开，本摘要不纳入其细节。节目预告下周春假停更一期新闻。

## 主题正文

### GPT-5.4：第一个「为 agent 而生」的模型

OpenAI 上周四发布 GPT-5.4，主持人形容它「seriously good」，并说「trust the model 这句口头禅在编码上从未如此成立」（`00:00:35`–`00:00:41`）。他引用 Augment Code 的官方评价：「这是我们用过的第一个感觉为 agent 工作流而生的模型——干净地做规划、出色地委派、始终如一地跟进到底而不中途迷失」（`00:00:48`–`00:01:01`）。主持人自述正巧在评测模型时看到新模型上架，切换后「立刻印象深刻、进展飞快」，并劝听众「还在轻视 Codex 或 GPT-5.4 的人可能正在错过」（`00:01:01`–`00:01:13`）。

### 人脑细胞打 Doom

此前在 The Changelog 第 639 期（`00:01:22` 提及，链接在 show notes）聊过的 Drew Wilson 曾提到他在 Cortical Labs 和 CL1 上的设计工作——如今「这东西跑起了 Doom，而且他们有视频为证」；主持人感叹「未来已来」（`00:01:22`–`00:01:39`）。

### 10x 工程师的黄昏

主持人转述 X 上 Mo（mobitar）的一条视频，触到「toll booth」隐喻以及那句扎心的自问：「为什么我还要手写代码，当这东西能更快、更好、近乎即时地产出？」（`00:01:45`–`00:01:59`）。主持人承认「我们都在绕着这种感觉踮脚走」，并公开邀约 Mo 上节目（`00:01:59`–`00:02:06`）。

### Detail.dev：把代码库送进「战阵」

主持人尚未亲测，但 X 上见闻足够多，于是分享：Detail.dev 会扫描你的代码库，用几个小时「以有创造性的方式折磨你的代码」，找出你「会庆幸提前知道」的严重 bug（`00:02:07`–`00:02:34`）。

### 值得一提的周边

- **Haptics 库**：把 iOS 式触感反馈带到 Web，支持 React/TypeScript/Vue/Svelte，地址 haptics.lochie.me（`00:04:07`–`00:04:30`）。
- **Handy**：免费开源的本地语音转文字 Mac 应用，按快捷键说话即录入，全部在设备端处理、音频不出本机（`00:03:29`–`00:04:01`）。
- 节目还插播了 Sonatype 的赞助段（核心提示：编码 agent 的知识有截止日期，它自信推荐的依赖包可能已披露多个 CVE，可用 sonatype 的 guide 核对）与下周春假停更公告（`00:02:38`–`00:03:25`、`00:04:33`–`00:04:40`）。
