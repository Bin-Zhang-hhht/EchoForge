## 速读

The Changelog 691 期，主持人 Adam Stacoviak 对谈 Amp（ampcode.com）创始人、Sourcegraph 联合创始人 Quinn Slack：Amp 已从 Sourcegraph 独立为一家 20 人、全员按联合创始人对待且已盈利的公司，节目围绕"代理写码、代理审码、直推 main"的新工作流展开——代理该住在哪里、谁记得你让它做过什么、代码评审向何处去。（`03:15–05:04`）

对正在把日常工作交给编码代理的工程师，最有价值的三条线：一是 Orb（云端代理）与"给代理一个家"，主持人为 tailnet 私有仓库的凭证时序问题现场推动了一次功能修复；二是永久、不可变、可检索的线程——人类意图被当成一等公民保存，不用于训练，commit 默认回链线程；三是代码评审的转型——从逐行 PR 评审转向视频、截图、性能报告等信号，amp 团队在线程内完成评审后直接推送 main，前提是长期共事积累的信任。（`06:31–07:05`，`23:02–26:59`，`32:50–38:43`）

更宏观的两点判断：模型已不再是最重要的变量——档位制取代了挑模型，开源模型"是真的追上来了"；以及 Quinn 对开源公地碎片化的担忧——GitHub 不可替代的是"与全世界一起构建"的公共品属性，他担心人人退回私有角落会让质量、专业化与连接感一起消失，却坦承自己还没有解决方案。（`43:19–44:36`，`59:56–63:12`）

## 主题正文

### 从 Sourcegraph 拆分：20 位联合创始人的独立公司

Quinn Slack 是 Sourcegraph 联合创始人，也是编码代理产品 Amp 的创始人，这是他第二次上 The Changelog。主持人回忆上次对谈时 Amp 才刚起步、价格还是"实价"——不补贴模型成本，当时被往期嘉宾比作代理产品里的"保时捷"（主持人原以为这比喻出自 Quinn 本人，Quinn 当场澄清是他人所说）。（`03:15–04:17`）Quinn 感慨他如今的构建方式"最近八周的变化比去年一整年还多"。（`04:21–04:30`）

最大的变化是公司结构：Amp 已从 Sourcegraph 完全独立为一家公司。团队 20 人全部按联合创始人对待，公司已盈利；Quinn 说他们没有接受外部融资，只有起步时的一小笔钱，并受益于 Sourcegraph 多年积累的客户信任。这份"全员身家都在里面"的状态，是他后来推行激进工作流的底气。（`04:30–05:04`，`38:44–40:01`，`72:23–73:12`，`74:40–75:28`）

策略上也与去年反其道而行：当时行业主流是"把一个人的用量塞进 20 美元订阅"、再配各种护栏，模型是唯一重要的东西；Amp 选择放开 token 用量，更贵，但更早看到不被拴紧的代理能走多远——如今这一点大家都看到了。（`05:09–05:56`）

### Orb：把代理放到你不必盯着的机器上

真正改变工作方式的是 orb（别人叫云端代理）：代理跑在你无需盯着的机器上，并行度不再受限于你这台电脑的散热。Quinn 认为这装不进旧流程——销售找产品经理、产品经理开 Linear/GitHub/Jira 工单、开发照单更快实现——并行化之后，旧流程直接装不下了。改名是因为很多人过去在别家云代理上体验不佳，换个名字能让他们愿意再试一次。（`06:31–07:05`，`18:46–19:20`）

主持人 Adam 是重度用户，但有个具体痛点：他的代码仓库只在自家 tailnet（Tailscale 网络）内可达，而 orb 实例化时要先 clone 仓库，凭证来不及就绪。他的土办法是用 `--no-tui` 参数在一台专属机器上跑 amp，用 Go 写了个编排器 amp runner：为新项目开全新的 git checkout（不是 worktree）、创建线程——线程之间还能互相通信；再配一个持有最高权限 API token 与 secrets 的"系统代理"负责调度全局。他给这套环境起名 dev lab 而非 home lab：几个 Proxmox 节点、35 台虚拟机。（`07:51–10:03`，`11:45–12:18`，`13:01–13:58`）

节目现场 Adam 顺势下了一个功能请求：让 orb 在需要仓库之前就能注入 Tailscale API key。Quinn 当场在 orb 里开线程、用听写口述需求——他强调听写是把想法送进代理的最快通道；界面上的档位旋钮从低到中到高再到超高，Quinn 平时最常用中档，超高档"当然能调到 11"。（`14:11–17:56`）节目末尾回看进度：问题本质是时序——orb 启动时默认假设仓库不需要凭证；现状已改为若环境变量存在，先启动 Tailscale 并加入 tailnet、再 clone 项目仓库，文档同步更新；Adam 则希望把这个 key 直接放进 amp 现有的 secrets 保险库，并让 Quinn 在另一台只有 tailnet 可达的机器上验证 clone。（`79:11–81:21`）

### 永久线程：把人类意图存为一等公民

Quinn 把当下称作"计算的黄金时代"：像互联网早期的 IP/TCP/UDP、Unix 时代的进程与文件一样，现在正是在定义代理时代的基本原语，而线程是他认为做对了的一个。（`23:02–23:50`）线程永久保留、不可变——可以回看七个月前的线程、从中"挖矿"找想法。主持人补充说，我们经键盘或语音倾倒进代理的大量想法，在别的工具里"像以太一样飘过"，能回溯的线程让它们沉淀下来。（`23:47–24:36`）

Quinn 批评竞品：在 Codex 或 Claude 的 CLI 里倾注心血，要担心上下文被压缩、文字被打乱——记录躺在人类不可读的 JSONL 文件里，也没有配套的检索工具；Claude Code 的本地会话过段时间还会被清掉。他形容这像"把写满想法的草稿纸立刻烧掉"。（`24:56–26:06`）Amp 的对应原则：人类关于构建的一切想法都是珍贵的，模型产出的每个 token 同样珍贵——两者都保存、可回访，但不用于训练；设置里确实有个"启用训练"按钮，但对几乎所有用户它是个无效按钮，放在那里只是为了回答"你们到底训不训"。（`26:08–26:59`）

更进一步的机制是：默认给 commit 附上线程 URL。理由是 commit 解释不了人类意图——一个月前说"我要这个"，对应 commit 却带着缺陷，光看代码很难知道当初想干什么；修 bug 的正确姿势本来就是"去问那个人"。Quinn 说自己措辞经过斟酌：如果不保存并使用人类意图，代理不可能把我们想要的事做好。主持人则把线程视为产物谱系的一部分：功能 PR 带上线程 ID/URL，日后排查根因时，掌握的是真实对话与叙事，而非猜测。（`27:19–28:44`，`30:42–32:10`）

### 代码评审的转型：从逐行阅读到查验信号

Quinn 认为评审分两层：确认代理做对了什么，这永远重要；但"改代码→开 GitHub PR→同事在网页上通读全部代码→往返评论"这套具体流程正在死去，且各地死亡速度不同。若公司仍强制旧流程，并行化毫无意义——东西只会堆积；反正评审要等一天，把 30 分钟摩擦降到 0 就没人在乎。（`32:50–34:05`）

这不等于"不用评审"。Amp 团队自己极少无审直推（他调侃为 Google"手气不错"式：一个 prompt 直接推 main），仅限个人一次性软件，或 amp 里只影响后台管理页、错别字级别的改动。他们看的是更宽的信号：代理录制的演示视频（必要时逐帧检查加载抖动）、截图、性能报告，再抽查大约 10% 的代码和关键文件；amp 还提供运行中 dev server 的门户，省去本机同时挂五个开发服务器的痛苦。他也直言：旧式 PR 评审里同事本来就未必逐行读过，大多也没跑过代码。（`34:16–36:17`）

Quinn 用思想实验收束：如果 amp 承诺代码出错赔十亿美元，你愿不愿意放心点那个按钮？人们愿意——所以问题只是用更现实的手段逼近同样的确定性，比如一段视频。合规层面，他澄清 SOC 2 并不字面要求 GitHub 上的阻断式代码评审，要求的是一组被证明有效的控制并遵循之。（`36:25–37:25`）

Amp 团队的实际流程：开新线程、通常不建分支；在线程里审看所有提交，也让代理审一遍；试 dev server、看视频；然后按住带动画的 ship 按钮直推 main（也可配置成推分支/开 PR）。Quinn 反复强调前提是信任与问责——这些人是共事最长约八年的老搭档，且"不是说每个团队都准备好了"：四个月里人数翻倍、彼此认识不足一年的团队，很难达到这种信任水平。他的判断是会有越来越多团队长成 amp 团队的样子，因为代理让团队规模变小、每个人的影响力和所有权变大——"真正了不起的技术出自一群疯子的小团队"，这会让世界更有创造力。（`38:00–41:47`）

### 模型不再最重要：档位制、订阅与代币经济学

约一个月前，amp 把产品切换到"档位制"：低/中/高/超高一条线性标尺，多数用户不知道也不在乎背后是什么模型。团队内部用量从约 80% Anthropic 模型切到约 80% OpenAI 模型，客户侧对开源模型的用量增长明显（具体型号 ASR 记为 GLM 5 2，未能独立核实）。Quinn 的判断：模型都已相当好，开源模型"是真的追上来了"，于是不必用最贵的模型也能拿到极好的结果——这改变了 amp 想要构建的东西。（`43:19–44:36`）

产品随之调整：推出 20 美元/月订阅（学生 10 美元），可复用用户已有的各家订阅，即将支持 OpenRouter 与 OpenAI 兼容端点。Quinn 认为如今最重要的三件事是：把信息从大脑送进代理的通道（即听写）、同时跑一堆代理的能力、以及运行和使用代理造出来的软件——"比软件更软"的个人软件被他视为真正的前沿，而不是去年那种"用 AI 从零复刻 Salesforce"的噱头。（`44:38–45:44`，`46:19–46:30`）行业面也变了：人们不再迷信基准测试，新模型首发日常常根本用不上——他把这部分归因于"政府对智能自由的限制"等因素（受访者观点）。（`45:49–46:13`）

关于订阅的慷慨会不会退坡，Quinn 用航空业类比回应"补贴会消失"论：训练模型的前置成本巨大，经济学上最优策略是把算力卖给任何出价高于边际推理成本的人——企业多付、个人少付，即所谓价格歧视；再加上锁定竞争者的动机。他说经济舱从来不是补贴——美国联合航空在那些座位上是赚钱的——所以这种分层定价会一直在。（`47:55–49:39`）

### "以呜咽告终"：编辑器、GitHub 与开源公地之忧

Quinn 现在所有代码都通过代理写，团队里几乎没人再进编辑器写码；他四个月前从 VS Code 换到 Zed，称它是最好的编辑器——但自己很少用。主持人同样放下了编辑器：Zed 是他的最爱（Nathan Sobo 团队、Rust、高帧率），VS Code 则始终不合他的工作方式。他对 PR 的态度是"信任但验证"：不逐行审视，扫一眼有没有不对劲的感觉，重点看真实运行的应用与视频——PR 界面在他嘴里是"死界面"，连让它放段视频都做不到。（`49:42–52:23`，`54:10–55:48`）

这一系列变化的节奏，Quinn 的形容是"以呜咽告终，而非巨响"。他自己是 GitHub 第 1976 号用户，amp 主仓库今天仍推 GitHub（amp 也将托管仓库，团队日后可能迁走），但他已经"不再去 GitHub"——它只是个 git remote；没有哪天开了大会决定迁移，只是它在工作流里越来越不重要。早年"逐编辑评审工具权限"的谨慎也是这样慢慢松掉的。他认为这是单向门：没见过用上代理构建方式的人再回去，若是一阵风潮早该出现大规模回头；主持人补充，他那些当律师的朋友"还有时间"，软件开发者是受冲击最深的行业，这股力量几乎无法抗拒。（`55:49–58:48`）

但 Quinn 真正担心的是开源公地。git 托管本身简单得"不值得自夸"，GitHub 不可替代的是那种"与全世界一起构建"的温暖感觉：彼此站在对方肩膀上、跨越边界，像 Wikipedia 一样——它有一万个理由变成污水坑，却成了了不起的东西；GitHub 没有发明开源，却把它放大了几个数量级。他担心碎片化让一切退回各自的"小屋"——质量下降、专业化下降、开发者的连接感消失；一个 11 岁的孩子本可以去看 Linux 和 Chrome 的源码，他不知道解决方案，但想弄清楚怎么保住这份公共品。（`59:56–63:12`）

主持人用自身实践佐证这堵墙正在被一块块拆掉：他的 git host 是一年半前自建的 VM（Gitea，S3 异地备份、tailnet 内私有），连 PR 与 npm registry 都在自己机器上——"退出 GitHub"纯属个人选择，不是反 GitHub。他观察到 amp 手里已有代码、项目、secrets、环境变量、工作区、多人协作，即将上线自定义域名——团队协作这一侧快齐了，但 Quinn 承认"全球连接感"是没人想清楚的缺口；他给出的方向类似 Costco 的自有品牌 Kirkland：如果有那么一条高质量、可 remix 的"10% 核心"，让代理帮你按需定制，全球共享的世界就可能回来。（`63:33–65:02`，`65:24–66:57`，`67:09–68:03`）

节目还回顾了 Sourcegraph Cody 的教训：把产品定义成"企业的 AI 代码聊天"，就注定承载不了 AI 的潜力；在 AI 时代，把"当下很好"的产品推向更大市场是最快的过时之路——必须始终贴着前沿。Quinn 说这未必是错误，"是它把我们带到了这里"。（`68:37–70:11`）主持人的总结是工作流正在迫使整个市场更替：从想法到"真实东西"的速度成了瓶颈，手写代码"直言不讳地说，已经不是可选项"；拿了融资的公司更不可能手写。Amp 未融资、已盈利、没有企业销售团队，Quinn 认为这正是他们能"怪"得起来的原因——若有企业销售团队，orb 早被改名叫云端代理了。（`70:52–74:22`）

主持人收尾把两件事并置：代理越来越快、越来越便宜，模型越来越不重要，稀缺的是意图——你真正想要什么，被记录下来、一个月后还能找到；而当代码纷纷搬进私人角落，失去的是开源建立的共享公地，"以及训练这些模型的语料库"。节目留了三个问题：代理有了家，你的意图住在哪里？谁能在你的意图上继续构建？若更多代码转私有，下一代模型与人从哪里学习？（`81:44–82:46`）
