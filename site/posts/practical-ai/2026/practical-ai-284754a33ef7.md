## 速读

2026 年 4 月 1 日——一个不是愚人节玩笑的日子：Anthropic 的 Claude Code 在约三小时的窗口里被下载者同时拿走了两样东西：可还原出约 50 万行专有代码的源映射文件，和一个带远程访问木马的投毒版 Axios 依赖。这期录制于事发次日的双人节目做了完整复盘：事件时间线、监管前情、以及泄露内容里真正值得工程师研究的三层记忆架构、严格写入纪律与 auto-dream 机制。适合所有构建 Agent 产品的开发者。

## 主题正文

### 完美风暴：三小时窗口里的双重打击

Daniel Whitenack 先交代了事件本体：在事发前一晚约三小时的窗口内下载或更新 Claude Code 的用户，同时遭遇了两件事。其一，包里多带了一个 `.map` 源映射文件——它本用于调试时在压缩 JavaScript 与人类可读的 TypeScript 之间建立映射——其信息量足以重建约 50 万行 Anthropic 私有闭源代码，也就是 Claude Code 的「内脏与大脑」；其二，Claude Code 依赖的第三方请求库 Axios 在 NPM 上被发布了恶意版本，内含远程访问木马，直接 compromiser 用户本机（`00:07:56–00:21:09`）。一位安全研究者宣布还原了源码后，社区迅速组织起「净室重写」（Clean-room rewrite）仓库，先用 Python、并行推进 Rust 版本（Chris Benson 表示对 Rust 线尤其感兴趣）；节目转述这个仓库创下 GitHub 历史最快破 10 万星的纪录，前两小时即破 5 万，原始仓库遭 DMCA 下架前已被大量离线保存。Chris 的预测是：架构既已公开，Anthropic 最优解就是顺势开源——反正 IP 已经在外面了，开源还能消解「为什么不学 OpenAI 的 Codex 开源」的批评（`00:13:57–00:17:25`）。

### 前情：被贴上供应链风险标签的三周

节目用不小的篇幅交代了事发前 Anthropic 的处境：2025 年末收购 Bun JavaScript 运行时（后成为事件的关键一环）；2026 年 3 月 3 日被美国国防部（节目中称其自命「战争部」）认定为供应链风险；3 月 26 日拿到法官的初步禁令冻结该认定；3 月 27 日又流出一份关于 Claude「Mythos」模型「因太危险而不发布」的博客——Daniel 对这类「模型太强大不敢放」的叙事表达了惯性怀疑。Daniel 还分享了两类真实反应的分裂：技术社区普遍觉得「供应链风险」的认定很荒谬；而受监管行业的客户则感觉地毯被抽走——如果建立在单一供应商上、政府一句话就能切断，那本身就是自己的合规负债（`00:01:34–00:14:18`）。

### 核心洞察：IP 在 harness，不在模型

这是全期最重要的一段。Daniel 点破：对 Claude Code 这类系统而言，模型本身并不是驱动性能的关键组件——真正的 IP 是包在模型外面的 agent harness:记忆如何管理、如何连接工具、如何跨会话持久化、如何唤醒、如何注入上下文。一年前如果泄露的是模型权重，业界会认为家底尽失；现在权重在不在手里都无所谓——把正确的 harness 套在任何模型上都能干出极强的活。Chris 把这上升到行业叙事层面：Opus 4.5 之后模型能力快速趋同（4.6、OpenAI 的新模型、开源模型都在同一水平线），「报道模型本身已经是过去式」，这次泄露是行业成熟度的转折点（`00:22:29–00:26:28`）。

### 泄露暴露的工程实践：值得学的三件事

节目中梳理了 Claude Code harness 里被广泛讨论的几个设计。其一是三层记忆管理：`memory.md` 常驻但只存「指针」——指向信息的索引而非信息本身；其下是按主题分片的离散文件，仅在相关主题出现时加载；最上层是一套自愈式检索——Agent 用优化过的 grep 式搜索去核对真实日志与文件，而不是相信自己生成的摘要。这套结构直指所有 Agent 开发者的通病：上下文熵增、记忆漂移，「越喂越笨」（`00:26:28–00:30:10`）。其二是「严格写入」纪律：只有当动作的发生能被环境验证——终端退出码、API 响应、文件系统状态——才允许写回记忆；Agent 声称「测试跑过了」而实际报错的幻觉由此被制度性拦截。其三是 auto-dream:面向长期运行的 Agent,约每 24 小时复盘观察与洞见、把有价值的部分合并为长期事实，防止记忆无限膨胀（`00:30:53–00:33:08`）。

### 争议与方向：反蒸馏、隐藏身份与 proactive 转向

泄露内容里也有让社区不满的部分。一个是「反蒸馏」旗标：在 Agent 的思维链里注入假工具、做推理掩码，专门用来误导逆向工程——Daniel 认为保护专有资产无可厚非；真正引发开源社区反弹的是 `uncover.ts`:它用于在开源仓库贡献中隐藏 AI 与 Claude 的身份、规避水印识别。Chris 指出这击中了 Anthropic 的品牌要害——一家以「安全与透明」立身的公司被发现在做严格不透明的事，开发者社区本来就拿更高的标准要求它（`00:33:08–00:36:16`）。

泄露的路线图还显示 Claude Code 正从「响应式」（响应你的请求、issue）转向「常驻式」——后台维护、cron 调度、定时唤醒——这正是开源框架 OpenClaw 凭借「心跳机制」走红的方向。Daniel 的判断是：不管走哪条路，准备好迎接 7×24 小时在后台待命、随心跳醒来的 proactive Agent;而 Pandora 的盒子已经打开，开源克隆会层出不穷（`00:36:23–00:39:32`）。收尾的三条建议很实用：认真设计 Agent 的记忆（分片加索引）；考虑把清理机制搬到后台、走向 proactive;以及把供应链风险当作 harness 的固有属性来管理——它与模型风险（偏见等）是两个独立的攻击面（`00:39:32–00:43:05`）。
