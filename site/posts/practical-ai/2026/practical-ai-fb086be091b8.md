## 速读

这期无嘉宾节目由当天的一则新闻切入：IBM 股价单日暴跌 25%，两位主持人由此展开一场「后 Agent 世界」的经济学推演——企业预算为什么从软件挪向硬件，开源与微调为什么重新回到话题中心，企业软件的 Agent 化该走连接器还是自有代理，以及人在其中的位置。适合关心 AI 对软件行业与组织冲击的决策者和工程负责人。

节目价值在于把零散新闻拼成一条因果线：技术同时替代旧技术与人力流程，资本随风险重新配置，交互方式转向 agent-to-agent。所有市场数字与走势判断都来自主持人当天的转述与推演，属观点而非投资结论；Chris Benson 自己也说明，这是他计划中的「后 Agentic 世界」写作主题的公开推演。

## 主题正文

### 一根引线：IBM 暴跌与同板块的连锁反应

Chris Benson 当天早晨从新闻里得知 IBM 股价单日下跌 25%。他随后查到的数字是：约 700 亿美元市值蒸发，为五十多年来最差的单日表现，幅度超过 1987 年黑色星期一时期的损失；《纽约时报》称之为「煤矿里的金丝雀」。这组数字来自他当天的检索转述，本篇不对其做独立核实（`00:03:16–00:09:18`）。

Daniel Whitenack 随后补充了同日观察：Workday 跌约 10%、Salesforce 约 9%、ServiceNow 约 8%、Adobe 约 6%，而上涨的是 NVIDIA、Intel 等芯片商——他还不忘加一句「除非我的 Agent 在幻觉」。上涨被归因于企业「恐慌性购入」硬件，以及注意力转向与 Mythos 相关的网络安全话题（`00:25:53–00:27:13`）。

### 预算大挪移：企业软件失血，硬件与基建吸金

两位主持人把这轮下跌拆成几股力量：AI 厂商拼命提高粘性以收回巨额投入；用户恐慌性买入硬件以求「不被涨价挤出」；Anthropic 等公司把重心从模型转向实施与服务（`00:07:27–00:09:18`）。最关键的一条是企业预算的挪移：IT 预算正从企业软件与服务，转向硬件与基础设施——因为未来的 Agent 用法（长上下文、长时运行、进程常驻）意味着更高的推理开销，企业想先囤好算力，避免未来被定价权拿捏（`00:09:18–00:10:18`）。

Chris 认为这不是一次性冲击：紧急的资本重新配置会持续发生，受影响的首先是员工与「历来被视为基石」的内部职能（`00:10:18–00:12:47`）。

### 双向挤压下的应对：开源、微调与自托管回归

挤压来自两个方向：美国的闭源模型贵且受出口管制约束；原本作为退路的中国开源模型，也因中方开始意识到其经济价值而可能受限。Chris 把这描述为双方都在给自己的优势能力「上保护」，而企业则在两边挤压下重新分配预算（`00:10:18–00:12:01`）。

衍生的灰色地带也随之出现：两位主持人聊到「中国 token 黑市」——因为服务对大陆用户屏蔽、支付困难，出现了转售西方平台折扣 API 的中间商生态。Chris 的评论是，为政治目的施加的管制几乎必然催生黑市，这不该令人意外（`00:12:47–00:14:41`）。企业端的应对包括寻找非美非中的开源权重来源，以及一个明显的回摆：曾经被认为「模型够好不必做」的微调，随着小模型在特定任务与边缘场景上的普及重新被提起；Unsloth 这类能在笔记本上微调的工具被点名（`00:14:41–00:16:02`）。

经济账也随之改变：Agent 从笔记本上的个人助理，变成在云端连续运行数小时、数天甚至数周的长期进程后，按量计费的 API 与自托管小模型的成本结构完全是两回事（`00:16:02–00:17:15`）。

### 企业软件的 Agent 化：连接器、自有代理与 agent-to-agent

Chris 观察到的下一阶段，是循环中纳入数十万乃至上百万 Agent、Agent 之间大量协作的形态；Daniel 用自家客户验证了这个速度：一家公司已有约 7 万个 Agent 在运行，另一家约 6 千——「这不是五年后的未来」（`00:17:15–00:20:32`）。

面对冲击，企业软件厂商大致有两种姿势：一是 NetSuite 式的「连接器」路线，把价值锚定在自己的数据组织与功能上，通过 MCP 等接口暴露给 Agent 生态；二是部分垂直软件商选择不接入通用生态，构建自有专有代理（`00:21:39–00:22:38`）。Chris 的判断更激进：未来跨系统的交互将以 agent-to-agent 的方式发生，没有人再进入你的 GUI；厂商要设定的是权限与 MCP 配置。他顺势指出，「如何在大规模下管理 Agent 与资源」本身就是一片创业空白（`00:22:38–00:24:44`）。他还提醒，连「loop 工程」这样的热词都只是过渡性概念，预计年内就会被下一轮演进取代——企业该做的是掌握当下，并准备未来的代理式接口（`00:24:44–00:25:49`）。

### 人的位置：别抱旧角色，按结果重新规划

两位主持人都强调这不是单纯唱衰：技术改变的是人的角色与活动，而非把人完全移出。Chris 的建议直白——抱着旧角色不放不是好策略；他引用当天看到的 George Lucas 的话，把抗拒比作「汽车时代还攥着马车」（`00:27:23–00:29:07`）。

节目尾声引申到一篇 Anthropic 近期的论文（可言语化的表征构成语言模型的全局工作空间）：Daniel 概括其要点为，模型在「路由与上报信息」上的功能能力在增强——不是说模型有情绪或意识，而是这种功能能力正是 Agent 化转型的关键；Chris 则围绕「意识本无公认定义」展开：如果结果等价而实现路径完全不同于哺乳动物大脑，算不算数，目前更多是哲学争论（`00:29:34–00:33:37`）。落回实践，Daniel 转述了一位客户的建议：与其纠缠每家厂商的代理架构，不如在「结果」层面思考——要达成什么结果、需要哪些人的输入（`00:33:37–00:34:20`）。
