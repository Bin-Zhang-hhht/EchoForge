## 速读

本期 Chris Benson 单独主持，对话 Agentic AI 基金会副主席 Angie Jones。这家基金会由 OpenAI、Anthropic 与 Block 在 Linux 基金会下共同发起，为 MCP、AgentsMD、Goose、Agent Gateway、A2A 这些智能体标准与开源项目提供中立的家。

Angie 到基金会前的最后一个角色，是在 Block（Square 与 Cash App 的母公司）负责教全公司 12,000 人使用 AI agents。所以这期一半讲标准与治理，一半是她亲手推组织级落地的实战经验：对非开发者先给即时可见的好处，对开发者用 1% 创作者带动全组织。适合关注智能体标准化、企业 agent 推广与开放治理的听众。节目对具体项目的描述多为嘉宾口述，个别模型与产品名在转写中不稳定，本文不引用这类细节。

## 主题正文

### 标准为什么要搬进"中立的家"

Angie 的底子是传统工程师：IBM、Twitter，再到 Block 做工程管理，期间还参与过一个跨境资金移动协议，从此熟悉开放标准的运作方式（00:01:58–00:05:20）。2024 年前后她在 Block 的任务之一，是教会全公司 12,000 人用 AI agents，公司还造了内部 agent Goose 供工程师自动化测试、辅助编码（00:01:58–00:03:16）。

基金会的契机是 MCP：这个让 agent 连接应用与工具的协议出自 Anthropic，但不应由单一公司拥有。于是 OpenAI、Anthropic 与 Block 三家一起，在 Linux 基金会下成立了 Agentic AI 基金会（00:05:20–00:06:22）。基金会 2025 年底成立，目前已收纳五个项目：MCP；AgentsMD（OpenAI 发起，规范代码库如何向 agent 传达操作说明）；Goose（Block 出品，最早的开源 AI agent 之一，提供 agent 运行时）；Agent Gateway（来自一家叫 Solo 的公司，用于中继并管控企业内的 MCP 与 A2A 流量）；以及录制当周刚加入的 A2A——Google 的 agent 到 agent 协议，用于 agent 之间委托任务与协作（00:20:32–00:23:27、00:33:12–00:34:51）。她的判断是：项目放进中立的家，别的公司才敢在其上构建产品，不必担心路线图只反映某一家公司的目标（00:22:21–00:23:27）。

### 向非开发者推广 agent：先给即时可见的好处

在 Block 推广时，最难的不是技术而是变革管理：要求做了几十年本职工作的专家换掉熟悉的工作方式，还要面对恐惧与抵触；当时工具也只有命令行，连接 MCP server 要手工拷贝 JSON（00:08:44–00:09:50）。她的姿态是站在两个极端中间——不吹捧也不贬低，坦诚 AI 的强项、弱项、该用什么不该用什么（00:09:59–00:10:40）。

突破口常是数据：用 agent 加 MCP server 让业务人员几秒钟拿到数据库里的记录，而过去的流程是向别的团队提需求、等报表、再自己琢磨（00:10:40–00:11:40）。先让人在与本职无关的小事上建立信任，再逐步扩大委托范围，直到每个人都找到"这活 AI 干不好，我自己来"的边界（00:11:40–00:11:53）。

### 面向开发者：1% 创作者带动全组织

工程侧的情形更微妙：工程师们用上了，但"没看到开发速度的明显变化"，她判断那只是冰山一角，距离自主工程组织还差得远（00:03:49–00:04:17）。加上 2025 年 11 月前后新一代模型能力才明显跃升，早期试过一次就放弃的开发者不少（00:13:39–00:14:10）。

她借用了 1–9–90 法则（1% 创作者、9% 尝试者、90% 消费者）来分配力气：不指望 3500 名工程师同时上手，而是从每个关键仓库——前端、后端、iOS、Android——抽人组成约 50 人的"创作者"小组，请经理给每人 30% 的时间，并先逐一取得这些一线经理的同意（00:14:40–00:16:23）。这群人一起试错——很多技巧"在 web 上好用、在 mobile 上不行"——然后把有效做法固化进仓库本身：上下文工程、agents.md、agent skills，让任何 agent 指向这个仓库都按团队想要的方式工作；创作者再通过内部分享把结论带给各自的团队，替所有人过滤噪声（00:16:44–00:18:25）。

### 工作组怎么跑得比传统基金会快

成立前他们自己就问过：要不要做基金会？基金会出名的慢。结论是必须做，但不能按传统节奏——工作组的成员不是业余志愿者，做标准就是本职工作的一部分；自家产品要构建在这些标准上，所以有动力快速收敛（00:37:37–00:38:55）。竞争者之间的氛围也出乎意料地合作：公司之间可能在社交媒体上互怼，工作群里照样一起定标准；她推荐去 MCP 的 Discord 服务器看，协议内部就有几十个工作组在做实事（00:39:23–00:40:44）。

她把工作组的产出比作"大家一起定规则、一起画棋盘，然后再竞争"：以 agentic commerce 为例，Visa、PayPal、Stripe 谁也不想让另一家支付方单独把标准做出来（00:20:54–00:22:21）。

### 全球视角与未完成的议题

这个职位把她从北美技术圈的气泡里拉了出来。中国是移动优先，北美偏 SaaS 文化，所以中国对 A2A 这类"app 到 app"的协议需求更直接，她举例说微信生态里已有此类多 agent 协作（00:25:22–00:26:25）。欧盟 AI 法案会改变系统透明度要求，只要服务欧洲用户，无论公司注册在哪里都要遵守（00:28:41–00:29:02）。她还提到 Anthropic 不久前发布水印相关论文与博客后引发不少反弹，基金会里有一个工作组在讨论相关标准，但明确说"还没解决"；所有工作组公开，任何人都能旁听和发言（00:29:02–00:31:19）。

展望上，她判断 AI 会像手机和互联网一样进入普通人的日常，但普通人现在大多还没真正用上；她希望人类找到中间地带，"不要把一切都交给 agent、自己反过来给 agent 打工"（00:42:08–00:44:00）。
