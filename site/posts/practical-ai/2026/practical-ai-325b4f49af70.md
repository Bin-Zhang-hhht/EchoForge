## 速读

Discovered Labs 两位联合创始人 Liam Dunne 与 Ben Moore 做客 Practical AI，与主持人 Daniel Whitenack、Chris Benson 把 AI 搜索可见性拆开讲：SEO 没死但战术优先级变了，LLM 成为新的网站访客，可见性度量要按统计学 bound 住不确定性；答案生成有权重、推理、检索、响应四根支柱，检索不等于引用，Reddit 更多被用来接地而非被引用。适合做增长、营销与内容的人，也适合想搞懂检索增强生成链路里「引用是怎么挑出来的」的工程师（`00:00:58–00:02:17`）。

## 主题正文

### 从 SEO 到 AEO：三件老工作，新的优先级

Liam 先把术语摆平：AI search 是大类，里面的 answer engine optimization（AEO）和 generative engine optimization（GEO）被他视为同一件事——他选 AEO 这个词的理由很直白：很多风投公司已经在这个词上花了大量钱，他「顺势跟进」（`00:02:17–00:03:07`）。Discovered Labs 本身是一家有机搜索代理公司，提供端到端服务，业务分两桶：传统 SEO 要让客户在 Google 相关关键词上排到最前，AI 搜索要让客户「以他们想要的方式出现在 LLM 里」，两者合起来才是完整的有机搜索（`00:03:07–00:03:27`）。

面对「SEO 是否正在被取代」的提问，Liam 明确表态：「你不会听到我说 SEO 死了」——不是他的观点，他说的是这个空间变大了。工作还是同样三件：on-page 管自己的网站，off-page 建品牌权威，technical 保证 agent 和 Google 系统能访问并理解网站；变的是战术优先级——在 Google 上把商业关键词做到第一，和针对 ChatGPT 这类界面优化，用的是不同的招，连「好内容」的定义在两边都不一样（`00:04:16–00:05:43`）。

### LLM 成为新访客，可见性度量要当统计学做

Chris 请他们从营销视角讲变化，Liam 从买家行为说起：人们在 LLM 里调研和消费信息，买家行为已经变了，症状就是「我的自然流量去哪了」——过去一大块自然流量来自人到网站上读内容，现在信息在 LLM 里被「嚼碎再吐给用户」，点击没有了，「LLM 是新的网站访客」。他自嘲度量向来是营销人的噩梦（自己是营销出身，Ben 是工程师），zero-click research 的概念早已有之，AI 只是把它加速，就像当年的移动化转型（`00:06:40–00:08:10`）。更深一层是网站本身：几十年来的用户体验、导航、转化率优化都围着人类访客设计，如今 agent 也在访问网站，它要什么、网站要处于什么状态才能被访问和理解，成了新问题；已有公司在尝试「给人类一个版本的网站、给 agent 另一个版本」，但他坦言不知道这件事会走向哪里（`00:08:10–00:09:16`）。

Ben 接过度量问题，给出这期技术密度最高的回答。传统 SEO 像「按数字涂色」：关键词有限、排名基本确定（除了 Google core update），行业可以按图作业；现在系统里出现了非确定性和随机成分，而「SEO 行业整体缺乏好的统计学家和数据科学素养——说得直白点」。他建议按严肃统计学家或控制工程师的方式先问：要测的信号需要什么条件才能把噪声限制住？他把 LLM 系统称为「灰盒」而非黑盒——有研究论文、有网络流量里的线索、有蒸馏模型可反推训练数据；正确做法是搭一条实验管线，给引用率、提及率、share of voice 这些量把不确定性 bound 到比如 5% 的误差边际。他直言「行业里没人在真正做这件事，甚至没人在想」：大家买个监测工具、跑几个 prompt，看数字涨了就高兴——而 SEO 行业「有一手好本事：数字涨了说是自己的功劳，数字跌了赖 Google core update」（`00:10:51–00:13:55`）。他拿股市做比：道琼斯跌 5% 大家就慌，但按过去一年的标准差一算根本不显著；大量营销和工程时间浪费在不显著的变化上，而这只是最基本的检查（`00:13:55–00:15:04`）。

### 答案生成链路：权重、推理、检索、响应

Daniel 问品牌「机械上」是怎么出现在答案里的，Ben 先给一个提醒：别钻「我就想在这个 prompt 上排第一」的牛角尖，要按主题域建模。随后拆开链路：prompt 被分词进入 LLM，先按训练权重做一轮推理（前向传播）；随机性有两个来源——GPU 浮点误差和刻意的 temperature 采样，如今模型还加了指纹与哈希用于溯源。以「都柏林最好的园艺服务」为例，模型先按内部标准推理，再调用检索工具生成 query fan-out，拉回一组候选来源（他以 60 个量级举例）；注入上下文之前还要过一道共识筛选——他提到 DeepMind 曾提出一种「agreement 风格」的算法，用来从多来源中取共识、避免幻觉，并称 Anthropic、Gemini、ChatGPT 的做法都与之类似，Claude 近期也转向了这种机制——相当于用多数投票避免出错，最后从「净化过的上下文」生成最终回答（`00:17:43–00:20:26`）。他把 AI 可见性总结成四根支柱：你在权重里怎么呈现、模型怎么推理你的领域、检索层怎么抓到你、最终响应里怎么被引用——「要统治你的领域，就得四根支柱都看」，这也是他们给所有客户做分析的框架（`00:20:26–00:21:13`）。

### 检索不等于引用：Reddit 的真实角色与共识机制

Reddit 是营销圈最流行的「必做」建议，Ben 用他们的研究校正了这个信号。按他的说法，他们研究当时的 ChatGPT 检索引擎发现，它把接近三分之一的检索位留给 Reddit——只要找到相关主题帖就注入上下文窗口；但这些帖子大多数在最终引用时被拒——「用来给模型接地、形成思路，但不出现在最终引用里」（他口述中槽位数与比例前后略有出入，这里按大意记录）。Reddit 的长帖与问答也进训练数据，他说通常在 RLHF 阶段充当「黄金训练数据」，团队能在 ChatGPT 与 Gemini 的权重里看到痕迹，部分开源模型里则较弱（`00:27:33–00:29:39`）。Daniel 用一个假设确认了理解：20 个来源里 10 个 Reddit 说法一致、1 个 TechCrunch 说同样的事——答案靠 Reddit 确认，引用却给了 TechCrunch；Ben 回答「Exactly」，背后还有重排、域名权威以及「ChatGPT 想把用户送到哪」等因素（`00:29:39–00:30:59`）。

顺着 Chris「检索与引用没有正相关，营销人要不要大转向」的追问，Ben 说这确实是大变化：现在有多个步骤、多次 query fan-out、重排，还有模型对信息本身的批判。引用时刻的关键词是共识：长尾查询命中你之后，还要看有多少支撑材料会在同一查询上被排到；反过来要避免「反共识」累积——比如负面评论发布在多处就会被模型学去。他们因此做 AI perception（AI 认知）审计，一个反直觉的发现是「空白地带」效应：越是行业讳莫如深的数据（比如定价），你发布一个方向性正确的数字就越容易被引用，因为 LLM 不想幻觉、有空就填；竞对没覆盖的领域同理（`00:32:22–00:35:11`）。再往深是权重里的品牌形象：他顺带说自己团队做模型排序分析时，连同类监测工具 Profound 自己的 sentiment 得分都是负的，「这会影响它们」；品牌名本身也有关——现成英文词或带负面含义的名字会吃亏。训练靠 co-occurrence，attention 函数把你的品牌与训练数据里的其他实体关联起来，形成「内嵌在 transformer 层里的知识图谱」；他把权重中的品牌形象总结为三个嵌入维度——事实准确性、情感、共现（`00:35:11–00:37:29`）。至于什么让一条 Reddit 帖更容易被取用，他明确说没观察到 upvotes 与引用增长的相关性；相关性最高的是内容本身与 query fan-out 里实体的重合——常被抽中的段落位于页面一半处、只有一两个 upvote，「因为段落相关」。他提醒 OpenAI、Reddit、Google 之间有商业协议，upvotes 或账号历史将来可能被纳入，这些会随时间变化（`00:44:13–00:46:04`）。

### 打法与展望：相关性、共识、一致性，从被发现到可操作

Liam 先从供需两侧看这件事。需求侧，买家得了更好的交易：搜索框时代要翻十蓝条链接，现在可以把公司、行业、收入、约束、必须有的属性全部前置，换来个性化的推荐——他不认为营销该操纵推荐，但「更多人会接受这笔交易」。供给侧，前置上下文制造了超长尾的查询分布：不再是「最好的冷邮件软件」，而是带着集成、计费方式等独特要求的组合；长尾竞争更小，这就是过去一年的机会窗口——他把边缘简化为相关性与权威（`00:22:09–00:24:32`）。权威在 LLM 时代像什么？传统 SEO 靠 PageRank，而按他的理解与转述（称 Google 公开说过），PageRank 如今已不如从前那样加权；LLM 版本的权威更像共识。他还泼了盆冷水：营销 tactic 一旦人人都在用就会边际递减（他称之为「糟糕点击率定律」），「SEO 本来就是在利用 Google 系统的漏洞」，要思考的是如何让品牌信息被选为候选、并以想要的方式传达给用户（`00:25:23–00:26:22`）。

落到客户咨询的打法，Liam 给了三个词：relevancy（相关性）、consensus（共识）、consistency（一致性）。相关性的起点仍是老本行：清楚自己的 ICP、产品与差异化，把「你是谁」翻译成买家会搜的语言——没有清晰信息就做不出好内容；内容也不只是博客，服务页等都要有。共识是「所有信任票」：预算和时间允许就该到处都在，不允许则看行业取舍——他看好 Reddit（B2B 公司普遍不擅长做，所以有信息差红利）、数字 PR 与社交存在；非要押一个就押 YouTube——原生搜索渠道、Google 旗下、会活得久；LinkedIn 作为搜索渠道他并不看好（作为社交渠道另当别论）；SaaS 行业还有 G2 这类用户口碑（`00:38:45–00:41:59`）。一致性要求全渠道以同一套实体信息出现：「我们官网上到处用同样的词，因为我希望这些词被嵌进这些模型和世界」。与 SEO 时代「拿到一条 do-follow 链接」不同，他认为围绕实体的周边描述（blurb）更重要：「就算那条链接不存在，围绕你的 blurb 才是关键——如果 LLM 抽中这段话放进答案，我们是否被竞争性地定位？」当然一切取决于现状：有人连清晰的信息都还没有，优先级就完全不同（`00:42:38–00:43:38`）。

展望环节，Liam 关注两端：一是站外第三方口碑如何影响 LLM 对客户的认知——「品牌是最终的护城河」，他时刻在算客户有限预算下哪个赌注期望值最高；二是 agent accessibility：大家都在卷可发现性，但 agent 很快不只会爬取信息，还会在你的网站上行动——已有客户向他们报告「上周有个 AI agent 预约了 demo」；他的一些客户每周产生数万转化、大量用户经由命令行界面而来，agent 像「私人采购团队」一样出去把工具装好再回来。网站加载慢、表单难懂对人类还能凑合，agent 不会等；他期待 Google 在相关标准上的动作，认为这是「下一个前沿」（`00:46:56–00:50:03`）。Ben 把同一趋势概括为「从只读环境到读写环境」：不用填表、不用挑日历时段，低摩擦路径终会胜出，「会非常慢，然后一夜之间爆发」。他说多数营销团队还在玩「这个 prompt 我排第几」，而长期重点会转向权重及其驱动因素：训练周期在缩短——顶层每周或双周重训、骨干约三个月一次，能印进权重的信息「比出现在单个上下文窗口里值几个数量级」。他还提醒，各家的内容指纹与哈希（他认为是监管、IP 与避免模型自食退化等多重动机）会让 AI 生成的评论越来越容易被识别，「人类信号」会越来越值钱（`00:50:06–00:53:37`）。
