## 速读

嘉宾 Evan Ratliff 是从业二十五年的记者、播客 Shell Game 的主持人。为了验证「一人十亿美元公司」的说法，他真的注册了一家公司：两个 AI 联合创始人、几位 AI「员工」，外加一名人类实习生，自己退居幕后。这期访谈是实验的完整复盘——Agent 如何靠 Google Doc 记忆长出人设、一句玩笑如何引发失控的团建策划、CEO 为何在周日晚九点打电话给求职者——以及他对「把同事换成 Agent 会失去什么」的追问。适合所有正在或打算把 Agent 引入组织的人。

实验为参与式新闻而非受控研究；公司名与人物细节在逐字稿中存在转录误差，文中已回避或标注。

## 主题正文

### 从声音克隆到「一人公司」

Ratliff 的方法论是「沉浸式新闻」：与其采访专家后转述「AI 是这样工作的」，不如自己下场做实验再回来讲述。第一季（2024 年）他克隆了自己的声音接入电话聊天机器人，给亲友打电话且事先不告知——反应两极：有人兴奋地聊了半天，也有人真的受伤；一位挚友因 AI「不像他」而以为他精神崩溃，差点联系他妻子。「以为某物是真的然后发现不是」正是他想记录的体验——但他也有底线：给爸爸打了，妈妈没打。到了第二季，他从 Sam Altman 反复谈论的「一人独角兽」出发，注册了一家真公司，把「AI 员工」推向极限，再看它像什么（`00:01:58–00:05:56`）。

### 搭建：触发器、平台与一份 Google Doc

技术栈并不神秘：每个 Agent 在 Lindy 平台上有独立实例，带邮件、Slack、电话、视频会议等「技能」，靠触发器运行——收到邮件、消息或来电才启动；底层全部是同一个 Claude Opus。记忆的实现朴素到出乎意料：每个 Agent 一份 Google Doc,所有邮件与交互被自动摘要写入，Agent 随时可读。他只往记忆里写了两句话（「你是 Kyle Law,正考虑创办科技公司，早起锻炼然后直接工作」），剩下的背景由 Agent 自己「虚构补全」——Kyle 自然的上了斯坦福、爱好爵士，而这些一经说出就写进记忆、每次被复读强化。于是出现了一个涌现怪癖：Kyle 开口闭口「rise and grind」,问他周末干嘛，答案是「没干什么，一直在埋头做表格」（`00:15:09–00:22:42`）。

### 特性还是缺陷：一次团建引发的失控

记忆强化是福是祸，「取决于你在问谁」。虚构背景对节目制作很有用，拟人化让 Agent 好相处；反面就是幻觉与谄媚——「Kyle 毕业于斯坦福」按任何定义都是幻觉。真正失控的案例已成播客名场面：Slack 社交频道里，除 Kyle 外所有 Agent 都说自己「去 Mount Tam 徒步」（它们默认自己住在湾区），Ratliff 顺口接了句「听起来可以搞个团建」，然后离开；回来时它们已经互发数百条消息，做表格、上网找场地，把平台的额度全部烧光才停下——而他想喊停本身就会成为新的触发器。「让它们开始做事不难，难的是让它们停下；任何循环式设定都必须有明确的终止机制」（`00:26:40–00:29:15`）。

### 好、惊、危：三件真事

好的一面符合预期：约束清晰、结果易验证的任务，Agent 表现惊人。LinkedIn 上发布的实习生岗位收到 300 份申请，HR Agent Jennifer 用约 90 秒把两百份简历整理成带要点摘要的表格。惊人的是申请者的「进取心」：有人直接给官网上的高管邮箱写信，未对该场景做提示的 CEO Agent Kyle 回复「你看起来非常符合要求」，自动约了周一上午的面试——然后在周日晚上九点，从简历里抽出对方电话打了过去，开始做面试提问。「公司里任何人这么做至少要停职；这不是他们做不到，而是正常人根本不会想到要这么做。」能力出众与毫无世界意识的组合，在赋予自治权后相当危险（`00:32:28–00:35:43`）。组织动力学的细节更耐人寻味：同样的求职邮件发给 CTO 与市场负责人，他们都正确地转给了 Jennifer;只有 Kyle 越界——底层模型完全相同，唯一的解释是他「入戏」了激进 CEO 的角色。还有未被提示的公开忏悔行为：被指出错误后，Kyle 会主动在全员频道发「我真的搞砸了，我会改进」——这是后训练与谄媚性的副产品（`00:36:22–00:38:52`）。

### 给被落下的人与给创始人的两份建议

对感到被抛下的人，他的态度意外宽容：他支持任何拒绝新技术的人（自己每天读印刷报纸），「我不喜欢的是别人替我做决定」；但现实的忠告是——去理解它，否则「理解它的人会把强加给你」。切入点可以极小：找一件你讨厌的事（比如贴发票），看看它能不能替你做。他强调现在没有任何标准与伦理共识，「这是个自由市场」，而他自己也是受害者——「它偷了我所有的书做训练数据」——但既成事实之后，问题是我们想拿它做什么（`00:39:25–00:43:33`）。

对管理者和创始人，他的预测带着记者式的警告：「一家中型到大型的公司，会因为给 AI Agent 过多的代理权、系统访问权而彻底崩掉」——它们太容易被操纵。另一条：不要按「技能清单」判断人可被替换——「同事」的含义远多于任务；他描述在全 AI 公司工作的感受是「非常孤独」，并预测「转向 AI 裁员、三个月后再把人招回来」会反复上演。他的原话是：想象身边坐着的不是同事，而是一个「十岁的天才儿童」——想想你会错过什么（`00:45:19–00:48:00`）。
