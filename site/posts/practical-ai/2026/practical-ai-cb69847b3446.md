## 速读

嘉宾 Jeffrey Quesnelle 是 Nous Research 联合创始人兼 CTO。这期节目有三条值得单独摘出的线：Hermes Agent 的设计哲学——最小硬编码功能，让技能与记忆由模型自主生长，Agent 越用越懂你；开源模型四年的「内幕史」——从 Llama 金色时代到中国厂商的增长黑客，再到英伟达宣布接旗西方开源；以及一套使用哲学——「Agent 是有无限耐心但缺乏创造力的人」，指挥它要像对外星人一样把所有默会说出口。适合 Agent 产品开发者与重度用户。

嘉宾对自家产品的评价带有立场；「GitHub 第一开源仓库」「周吞吐提升」等说法均为口述，文中按访谈观点呈现。

## 主题正文

### 从 Discord 到 Hermes Agent：一条开源路径

Nous Research 起点是「Discord 上的哥们儿」——一群担心变革性技术被少数闭源公司锁死的人。他们押注的是：研究空间尚新，独立研究者的一两个人的发现就能撬动千倍改进（「千倍黑客」），David 至少能上同一块场地和 Goliath 打球。两年前正式成立公司后，他们做过 Hermes 系列微调（强调「尊重你、不说教」，前推理论时代）、互联网分布式训练研究（回应「万一开源 AI 被立法禁止」的担忧），最后把内部为自动化学研究所做的工具开源——这就是 Hermes Agent 的起点：最早的提交全是模型训练功能，开源后「产品市场契合像开闸一样涌来」（`00:02:16–00:08:55`）。

### 开源的内幕：金色时代、Llama 4 失手与英伟达接旗

Quesnelle 给了一段坦率的「内场视角」。金色时代：Llama 的开源更多源于 Zuckerberg 的个人意愿，但确实哺育了一整代研究者。转折点有二：Llama 4 因几个架构决策失误，让 Meta 直面「三四亿美元买了个镇纸」的追问——一切顺利时没人问开源图什么；DeepSeek 时刻则把开源从商业问题变成了地缘问题，中国厂商发现「放开源模型」是冲上头条的增长黑客，于是西方开源退潮、开源权重几乎全部来自东方。他认为最近的重大变量是英伟达：黄仁勋在 GTC 主题演讲上宣布未来数年投入约 200 亿美元训练「西方出身的开源模型」——这是唯一一个商业逻辑完全自洽的赞助者，「不管谁赢，牌桌都是英伟达的」，可能改变西方开源的走向（`00:10:45–00:16:01`）。

对个人，他的判断是「单个人的杠杆从未被放大到今天这个程度」：Hermes Agent 最初的作者 Teknium 并非传统意义上的开发者，此前无法独立写出完整程序，却借助 AI 工具架构并建成了这个项目——每个行业都在等待一个有激光聚焦愿景的人（`00:16:01–00:17:53`）。

### 大脑与身体：模型不是全部，但仍然是零到一

他的类比：模型是大脑，harness 是身体。大脑仍是「真正的魔法」、零到一的部分；但智商 150 的瘫痪者能改变的世界，未必大过智商 95 的运动员——「更好的 harness 配更差的模型，能打赢更好的模型配更差的 harness」。模型只能输出 token,harness 才让这些输出在持久、有因果、时间向前的现实世界里落地。至于价值归属，他拒绝做硅谷式断言，只给了一条水流方向：未来会「为结果付费」——像雇佣员工一样，谁把活干成谁有价值（`00:20:54–00:24:25`）。

### 会成长的 Agent：技能系统与「拉斯维加斯订餐厅」

Hermes Agent 的核心设计立场是「Agent 应该越用越好」。他们刻意只内置极少的硬编码功能（跑代码任务、浏览网页），其余一切通过提示词引导其自发涌现，两大机制是技能系统与分层记忆系统。技能系统的「魔法时刻」：他坐飞机时让 Agent 订餐厅，网站层层验证码拦截，Agent 花了三四十分钟真实运行时间绕过前端、找到预订 API 后端完成订位，然后自主写下一条「拉斯维加斯餐厅预订」技能——第二天再订另一家，一步到位。要点在于：他们不在代码里设计技能，只在提示词里鼓励模型自我反思——「当你发现某个做法反复被用到、或完成了对未来有用的事，把它记进技能系统」。记忆系统同样分层：对你的偏好笔记、历次会话记录等，全部由模型自行判断何时调用。好处是模型迭代即系统升级——下一代 GPT 或 Opus 发布，Agent「直接变好」（`00:25:06–00:30:54`）。

定位上，第一目标用户是「想用尽 AI 能力的重度用户」，slogan 是「越用越好用的 Agent」;开源原生，本地模型是一等公民，也可托管。他们正在探索多租户与组织内协作，并且 100% 自食其力：Hermes Agent 自身 99.99% 由 Hermes Agent 编写；内部有一个经 MCP 只读接入全部后端基础设施的 Agent,从调试工具起家，一个月里自发积累了整个公司的运维技能——现在 Discord 里的支持人员可以直接问它某个客户账户的问题并获得根因分析。一个工程师用一次，全组织持续受益（`00:30:54–00:34:19`）。

### 使用哲学：无限耐心、审美缺失与对外星人下指令

自动化什么？他的准则是「Agent 是有无限耐心但几乎没有创造力的人」——找那些不需要创造力、但需要无限耐心的工作（读日志、查根因），而「给我们配一个 CEO Agent、CFO Agent」这种一对一映射是最典型的错误思路（`00:37:38–00:39:19`）。他自己七岁开始写代码、六个月前还自认写得比 AI 好，如今坦然承认那个时代结束了——「相当于把时钟拨回我八岁那年，可以再当一次早期入场者」（`00:39:19–00:40:23`）。

AI 缺的是品味：数学和科学是普适的，而人类的审美感扎根于共同的具身经验——出生、活在时间里、进化压力——AI 与这些完全隔绝，所以它会用「美学上令人不适」的方式解题，产出「 slop」——所有段落一样长的平均值文本。主持人 Chris 补充：模型回归均值，做不出真正新颖的东西，但那已经覆盖 99.9999% 的用例（`00:40:23–00:44:44`）。

由此得出最重要的使用建议：不要告诉它怎么做，描述结果与验收条件。用户最初的失控感来自想逐步指挥；正确姿势是目标导向加评估导向——「什么条件成立，我才认为目标达成了」。如果验收标准没说出口，不满就会永远持续：你抱怨产出是 slop,但 AI 心里「平均值就是最好的文章」。「向我解释得像五岁」要换成「向我解释得像我是外星人」——它确实是一个没在地球上长大的外星人，你们之间没有共享的默认前提。能把内心假设全部显式说出来的人（他们团队里的「LLM 耳语者」），就是这个时代的稀缺技能（`00:45:05–00:47:28`）。

### 收尾：「电脑知道」的一代人

商业目标之外，他睡前想的是更大的问题：社会本已滑向刷屏式的注意力消费，而 Agent 可能是又一块多米诺——「如果你的工作只是对 Agent 重复『去做那件事』，你作为人的成长在哪里？」Nous 自称「以人为本的 AI」:让你今天比昨天更好。他最深的忧虑是代际的——只需要一代人，「答案就是电脑知道的」就会成为孩子眼中唯一存在过的答案。五天前他刚生了女儿。悲观或行动，他选择后者——这正是 Nous 存在的理由（`00:48:17–00:50:41`）。
