## 速读

「开源模型什么时候追上闭源」是过去两年最持久的行业叙事，这期双人节目宣布它过时了。两位主持人先用 DeepSeek 例子把开源/闭源的四种获取方式讲透，再评点 Meta 弃 Llama 转向闭源新家族的冲击，最后给出他们的核心判断：模型已成为大宗商品，基准上那几个百分点的差距对多数用例无关紧要，价值正在转移到 Agent 编排、治理与监控——以及一套「什么时候选开源、什么时候选闭源」的清晰决策框架。适合正在做模型选型或搭建 Agent 产品的团队。

涉及 Meta 新模型家族的名称与事件细节来自主持人转述的媒体报道；基准差距为口述印象，非评测数据。

## 主题正文

### 开源/闭源到底指什么：同一条流水线的四种出口

Daniel Whitenack 用 DeepSeek 做了一次教科书式拆解：厂商通过离线训练产出「参数（权重）+ 运行架构的代码」，此后有四种可能的出口——做成 SaaS 产品（用户在网页上用，模型藏在幕后）；提供 API（仍跑在厂商基础设施上）；公开权重与代码（多数发布在 Hugging Face,用户可在自己的服务器或云环境运行，许可证有时宽松有时苛刻）；或被第三方做成托管服务（如 AWS Bedrock、Together AI 替你运行）。所谓闭源，就是权重与推理代码永远不出厂商机房——那是他们的 IP;所谓开源，就是这套东西公开可自部署（`00:08:32–00:15:36`）。

### Meta 弃守：西方开源的困境

Chris Benson 带来当周最大的新闻冲击：多年来西方开源阵营的旗手 Meta,在 LeCun 离开（他十年前续约的条件就是模型开源，这也是 Llama 系列一直开源的缘由）后，实际上放弃了 Llama——已发布的权重保持开源，但更新未卜，公司资源全面转向闭源新家族（逐字稿记为 MuseSpark）。这让西方开源雪上加霜：开源前沿本来就已是中国厂商领跑，而国防情报圈又有「优先西方模型」的安全偏好——「你很难在美国基于中国开源模型做方案再卖给美国政府」。开源开发者该转向哪里、客户会接受什么，成了现实的商业难题（`00:15:54–00:20:33`）。

### 基准差距与「谁在乎」：商品化论

差距还存在吗？Daniel 摆出基准事实：闭源的 Opus、GPT-5.5 与开源的 Kimi、Qwen 3.5 相比，开源仍落后几个百分点，有时略多。但他紧接着抛出「分裂性问题」：谁在乎基准？它和真实世界无关。Chris 从物理 AI 视角补刀：可穿戴与边缘设备用的根本不是巨型前沿模型，而是为特定用例设计的小模型；新闻里的基准擂台多少带表演成分（`00:20:33–00:24:07`）。Daniel 随后给出本期最核心的判断：一年前他还在为开源终胜欢呼，如今「用什么模型这个问题已经基本不重要」——模型是完整的大宗商品。他用中西部的餐桌比喻：食客不在乎盘子里的玉米和大豆是哪个等级的，在乎的是菜怎么做。对 Mythos 引发的网络安全恐慌，他的回应同理：无论那个模型发不发布，现有的 AI 加 Agent harness 能力已经足以颠覆网络安全——关键从来不在模型，而在人们怎么把模型接进 Agent 系统（`00:25:45–00:29:20`）。

### 价值转移：微服务类比与「依赖观」

Chris 观察到头部厂商的重心佐证了这一点：Claude Design 这类新产品并不是靠全新模型，而是把现有模型接上基础设施与工作流变成产品——「2026 年大家真正在卷的，是把模型变成一百种产品和服务的那套东西」（`00:29:20–00:31:04`）。Daniel 则回答了「什么能在模型厂商的碾压下幸存」：回想微服务时代，四五个服务还能自理，到成百上千个时，Datadog、Splunk 这类监控与根因分析产品成了离不开的粘性基础设施——没人会想自研，用了就回不去。Agent 世界正在重演：一个 Agent 背后已是多模型、嵌入、重排、MCP 连接、工作流代码与界面；当企业里有几十、几百、几千个 Agent 时，治理与策略执行、监控、MCP 服务器管理、Agent 间通信、目标追踪，这些才是高价值问题。在这个图景里，模型的角色退化为「依赖」——像软件依赖一样需要追踪、可能有漏洞、随时可替换，但「整个项目远比单个依赖重要」（`00:31:04–00:35:17`）。Chris 补充了边界：工具加速了粗活和接口重做，把数月的活压缩到几天几周，但 novelty 仍然要人带来——「不是一切都变了」（`00:35:17–00:37:50`）。

### 决策框架：什么时候开源赢，什么时候闭源赢

给听众的操作性总结：开源模型明确赢的场合——气隙环境、数据主权与控制、许可证约束、高吞吐大规模处理（便宜得多）；闭源产品赢的场合——作为托管服务提供的高可靠性与 SLA。而 RAG、自动化、MCP 工具调用、Agent 间通信、代码生成这些 Agent 时代的常见工作负载，用哪家的模型都能做得像样——决定成败的是周围的 harness。收尾建议一句话：少追模型新闻，多想你的业务需要什么样的 agentic harness、它能以什么新颖或渐进的方式解决你的问题（`00:37:50–00:40:13`）。
