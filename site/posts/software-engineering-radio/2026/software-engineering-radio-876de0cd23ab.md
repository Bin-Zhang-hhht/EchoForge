# AI 时代的工程经理：从运营评审的"参谋长"技能，到 triage 从 5 天到 9 小时

## 速读

LinkedIn 高级软件工程经理 Sonali Varde(二十余年工程管理经验)讲述 AI 落进管理者日常的真实形态:给运营评审配一个用自然语言教出来的 Claude Skill,让跨系统看板的例行汇总不再吃掉会议；团队自建的 bug bash agent 把全组 triage 时间从 5 天压到 9 小时；而凌晨 3 点被 agent 的幻觉带偏一小时的经历，让她反复强调人的第一性原理判断不可外包。

最值得带走的三点：token 用量只是采纳指标，吞吐要看"上线了多少举措、自伤事故有没有减少"；写代码提速之后,代码评审、部署与测试周期成了新瓶颈；对工程师经理的行动号召是"别焦虑，去上手"——你不必有顶级 IC 的吞吐,但要有共情并做他们的代言人。

## 主题正文

### 一周里的 AI:运营评审的"参谋长"技能

Varde 的一周从运营评审开始：她的组同时管着新旧两套系统，各有各的看板与工具，过去要把多个工具的数据手工汇成表格才能看清该关心的指标，每周还要开一小时的评审会听各位经理逐个汇报。变化是她建了一个 Claude Skill:用自然语言告诉它"我看哪些链接、我要从输出里找什么"，它每天自动跨系统汇总出日报——会议时间省了,"数据在不在"的扯皮没了，评审会直接从真正的洞察开始，还能按需把缺失数据自动邮件给上级。她把这个用法比作"参谋长"(chief of staff)技能：像给人类同事交代任务一样交代它，它复述理解、给出产出，之后还能反复对话打磨，甚至排成每天早上跑、评审会前跑。（`00:01:15–00:06:24`）

对比一年前的"提示词时代"，她认为当时大家想得小：提示词要么用来解决客户/业务问题，要么当 IntelliJ、Eclipse 式样板代码自动化的升级版—— compartments 化的用法，没人想到它能端到端地自动化整条工作流。（`00:06:24–00:07:46`）

### 两次被误导:human in the loop 的分量

节目没有停留在成功案例。她讲了自己的两次"翻车"。一次是用 AI 修 UX bug:她来自后端背景，对无障碍、回流(reflow)这类前端架构不熟，直接采纳了 agent 给的修法，结果 tech lead 在代码评审时指出实现错了——常规流程里没有 bug,问题出在 reflow 架构里。结论是：即便有 AI 工具，人的判断、对上下文与深度的理解、硬调试的功力仍然至上；要刻意练习"什么时候完全信任、什么时候带着戒心信任"。（`00:07:46–00:09:47`）

另一次更疼：团队把 agent 接进了 on-call 告警，凌晨 3 点被告警叫醒，她试着用 agent 调试，结果输出"到处都是"，被它的调查带偏了将近一小时——agent 不理解这套系统、产生了幻觉。最后她只能弃用输出，回到第一性原理，沿着技术栈一层层亲自排查。她的要求是：永远用第一性原理和系统思维去挑战 agent 的产出，关键系统尤其要有这种严格性。（`00:27:57–00:29:47`）

### Bug bash agent、skill 与 agent 的分界,以及 Eisenhower 选任务

团队自建工具的代表作是 bug bash agent:跨职能团队做端到端 bug bash 时仍在同一张表里记 bug,但之后的分诊、导入 Jira、区分 blocker 与非 blocker 这些流程性工作交给 agent——多个团队多次 bug bash 叠加，省下的经理与 tech lead 时间相当可观。skill 与 agent 的分界她也讲得清楚：skill 是可分享的原子单元，你按需调用，它做汇总与综合；agent 代表你执行任务；原子 skill 组合起来可以成为 agent。（`00:10:06–00:13:38`）

选什么来自动化？她没用 AI 推荐技能，而是周一早上在脑子里过一遍 Eisenhower 矩阵：那些重要但不紧急、纯粹因为繁琐而总被拖成紧急的任务，就是最该做成技能的——"重要的事不该被拖成急事"。省下来的时间流向哪？更多产品与平台想法被做成小型原型：不必再花大时间做 deck 说服跨职能伙伴，原型本身就是对齐工具。（`00:12:40–00:14:48`）

### 团队采纳之路与经验的不对称

团队的采纳大约在九到十个月前起步，最初只是选用 cursor、Windsurf 还是 GitHub Copilot 并跟踪采纳率；真正的转折是 1 月初 Claude Code 发布加上黑客松周——那一周 Replit 做应用 mockup、Claude Code 写码、Gemini 做演示，对她和一批组员是"真正的转型时刻"。2 月之后策略变成：把采纳做成指标，经理也一起用，早期采用者在团队 shareout 上展示自己做的 agent,技能和插件开始"传染"，如今全组写码做事都在用 AI 工具。（`00:15:00–00:17:52`）

谁用得好谁用不好？她观察到一种经验的不对称：资深工程师的肌肉记忆太强——on-call 时看哪个看板、查哪种日志、用哪条正则,自己上手比向 agent 解释更快；新手反而更容易受益，凌晨被电话叫醒时可以直接问 agent"我们组的代码库该找哪类错误、哪些指标超过了阈值"。她自己的体会更进一层：肌肉记忆只覆盖自己的仓库，跨团队、跨组织的边界恰恰是 agent 帮她跨过去的——先自己多排查一会儿，再决定要不要 call 别组的 on-call。（`00:17:52–00:20:38`）

### 工程师成了 Agent 管理者,评审成了新瓶颈

"工程师在变成一支 Agent 团队的经理"，主持人如此发问。她的回答带着系统思维者的宽容：工程师本来就习惯多线程，新人一口气开四五个 agent 也无妨——只要在 token 预算内，在失败里学习就好；关键是好奇心与学习力：你读 agent 的输出吗？你能解释两三个 agent 为什么互相冲突产出了错误结果吗？会复盘的人自然学会下一次只给一两个 agent 派对任务。效率高的工程师确实同时背上更多项目，但三倍吞吐还谈不上——取决于架构复杂度、跨团队依赖与新旧系统比例；建码时间在缩短，省下的时间转向评审、部署、运维卓越与硬调试。（`00:20:38–00:25:22`）

一对一面谈的内容也变了。她举的 skip-level 例子已成为团队传说：一位刚入职的年轻工程师问她"你的绩效怎么评"，她说是全组 triage 时效、当前 5 天；对方回去研究所有流程后做了一个 triage agent,把所有工单的 triage 时间压到了 9 小时——此前的分诊工具是纯文本的，他给它加了可视化等能力。这件事让她意识到 1:1 的功能在升级：公开自己的指标与思考，能点燃别人"这也可能"的想象。（`00:25:22–00:27:53`）

代价是瓶颈转移。她与团队最资深 IC 有一段互怼的玩笑："我说管理的乐趣回来了，他说我评审的乐趣没了。"评审现在是最大的瓶颈：资深 IC 们守着质量的大门，同时要想清楚用多少自动化让评审不成堵点；部署与测试周期同样需要真正的创新。细分来看：CRUD 类 API 的构建与评审已经基本被自动化接住；前置的系统设计思考(离线计算、近线、pub/sub 架构怎么拆)反而有了更多时间；调试离线数据任务快了；但涉及数据血缘与数据政策的部分 AI 还不理解，测试、部署与基础设施侧的收益尚未显现。（`00:29:47–00:33:30`）

### 度量、人人皆 builder、招聘与"别焦虑"

度量上她的立场对管理者很实用：token 用量是采纳与使用指标(能看出谁在用 plan 模式、谁在用 agent 模式)，不是吞吐指标；吞吐要看团队做了多少实验、上线了多少举措、自伤性事故有没有减少；她正在推动团队度量主干被阻塞频率、PR 被回滚率这些系统健康指标——"AI 指标往上的同时，系统指标不能往下"。至于"我们的 story points 变多了"，她归入举措数一类并顺带补了一刀：story points 本来就是拍脑袋的估计，作用是提前暴露风险；现在有意义的问题是 OKR 里多少举措真正roll out到了生产。（`00:33:30–00:37:13`）

方法论层面她认为敏捷实践仍会被各团队按需剪裁,但边界正在消失：PM 和设计师不再只提需求，他们直接参与构建、把产品策略写进代码——"人人都是 builder",敏捷团队的组成在一两年内会变。招聘侧唯一的模块级变化是新增"AI native"考核：看候选人解题时如何使用 AI 工具(评分标准还在内部校准)；她本人的面试则更多问好奇心、适应性与学习意愿。入职仍是 30-60-90:30 天不要求熟练,60 天要求广泛使用团队的 AI 工具，90 天要求对产出负全责——这一点没变，只是任务的复杂度上去了。专家也不会消失：她自嘲后端出身看不出直角圆角的差别，而团队里 UX 专家"知道世界级 UX 长什么样";架构评审里被论文和 GPU 数学震到的时刻提醒她,人对"好、公平、伟大"的判断无法外包给 agent。（`00:37:13–00:44:49`）

收尾的行动号召简单直接：经理们之所以是技术管理者，因为曾经是技术负责人——去把那部分身份捡回来，亲手用团队在用的工具、亲手做一件团队排期里的事，这样才能与上级、同侪有质量的对话。对 AI 带来的职业焦虑，她的原话是"别焦虑，去上手"(learn by doing):你不需要跑出顶级 IC 的吞吐，但要学会他们的痛点，做他们的代言人。最后守住一条底线：保持人的判断与直觉在线，多问问题、练深度审视的肌肉——"做个有人味的人，有同理心，用这些工具，别被外面的焦虑带跑"。（`00:45:11–00:49:30`）
