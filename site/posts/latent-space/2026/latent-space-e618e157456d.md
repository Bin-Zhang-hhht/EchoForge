## 速读

Ethan He 的职业轨迹横跨了视频生成的全部关键节点：与 ResNet 作者共事、FAIR 自监督学习、NVIDIA Cosmos 世界模型与 Megatron MoE、然后在 xAI 用三个月从零造出 Grok Imagine 首个模型。这期访谈把视频生成的训练法、成本账、推理加速与世界模型路线图一次讲透。

最值得带走的三点：视频模型的智能主要来自语言模型——Cosmos 里 7B 的扩散模型配上一个更大的 LLM 提示词改写器才好用，"扩散模型很蠢，按字面执行指令"；训练视频模型的隐藏成本是几十 PB 的存储与出口流量，每月数百万美元起步；以及他的核心押注——下一个 Sora 不会是更好的视频模型，而是能规划、生成、编辑、迭代的视频 Agent。

## 主题正文

### 三个月从零到一：迭代速度就是一切

Ethan 在 2025 年中加入 xAI 时，视频与多模态"没有基础设施、没有数据、没有模型"，几个工程师三个月发布了 Grok Imagine 0.9。他归因于三点：第二次干同样的事（Cosmos 建了一年）、一支沟通带宽极小的强团队（每天一个同步会，其余时间全在造）、以及 xAI 现成的数据与推理基础设施底座（`00:03:24–00:05:46`）。他反复强调的度量是迭代速度："从获取新数据、设计新算法、训一个新模型到评估它比上一版好，这个循环一天能跑几圈？"有强基础设施和大算力，你就有更大的容错缓冲、能发现更多 bug。而"很无聊但真实"的经验是：大部分模型质量提升不来自新算法，而是来自修数据管线和训练管线里的小 bug（`00:05:46–00:07:00`）。一个前瞻判断：编码模型让实现从几周缩到几小时后，算力可能重新成为迭代瓶颈——"你现在有足够算力去尝试所有想法吗？"

### 训练法与成本账：先图像后视频，存储比想象贵

方法论是标准流程但每个环节都有讲究。第一步是数据：互联网上视频与文本天然不相关——"视频是山景，标题是'今天真开心'"——所以必须造 100% 合成的文-视频对。Cosmos 的标注协议是要求标注员"把视频描述到盲人听完文本就能在脑中重建"的程度，之后用 VLM 批量生成字幕；生成训练里还会留一小比例无文本数据帮助泛化（`00:10:28–00:13:43`）。第二步是压缩：1000×1000 的图像就是一百万个像素 token，transformer 训不动，所以要训 VAE tokenizer 把 patch 映射到连续潜空间——直接拿 MP4 压缩码流当 token 有人试过，但那种潜空间模型学不动（`00:13:43–00:20:52`）。第三步的时序压缩是个权衡：8×8×4 的压缩把四帧压成一个 token、上下文省四倍，但逐帧压缩才可能有实时交互——时序压缩天生带延迟（`00:20:52–00:22:10`）。顺序上必须先训图像模型：十亿图文对的映射密度远高于十亿文-视频对，视频 token 太多，直接训视频会让模型"没见过足够的语言 token，理解不了人类意图"（`00:17:37–00:18:53`）。

成本侧有一笔很少人算的账：假设 10 亿条视频、每条 5MB，光原始视频就是 5PB；VAE 特征通常还要另存同等量级——几十 PB 的存储加出口流量，每月数百万美元起步，还没算 GPU（`00:32:10–00:35:44`）。模型规模上，开源的 LTX 有 19B 稠密参数，MoE 方案可能是 20B 激活、数百 B 总量——与中型 LLM 相当；Cosmos 披露过数十万亿视觉 token 的训练量，"训练视频模型的成本与 LLM 相当"。推理侧则完全是另一个故事，最大收益来自 step distillation：流匹配模型要 100 步、蒸馏模型甚至上千步，蒸馏让学生模型从教师模型学"少数几步生成"——强弱蒸馏之所以成立，是因为教师拟合的是整个互联网的分布，而学生只需拟合"教师这个模型"的输出，分布简单得多；生产环境通常只跑几步，Cosmos 是 4 步、8 步，Transfer 这类图到图任务可以 1 步（`00:37:04–00:39:22`）。别忘了 GAN 是 step distillation 的开山鼻祖——判别器把任务简化成"这张图真不真"，比"从互联网重建真值"容易得多，如今一致性模型、分布匹配蒸馏与 GAN 常组合使用（`00:39:22–00:40:31`）。

### 音视频对齐与世界模型的三要素

Grok Imagine 0.9 是他口中"第一个大规模部署的音视频联合生成模型"。难点在模态对齐：文本-视频只是松对齐，而音频与视频需要时间步级别的精确对齐——模型必须有时间感知。他用一个笑话点破 LLM 缺时间感：让它干个 12 小时的任务，1 小时后回来说"我已经干了两天，穷尽了所有办法"（`00:41:21–00:46:47`）。音频本身还有双重性：语音大体是带特征的离散文本 token，音乐则是高度连续、没法用语言模型的离散 token 建模的东西；而且多数 VLM 不懂音频，给音乐写"能让聋人重建听感"的描述（相当于字幕脚本）是大量的合成加人工数据工程（`00:42:44–00:45:15`）。

他对世界模型的定义刻意务实：实时、可交互、长视界的视频。实时意味着专业游戏玩家要求的毫秒级响应；交互意味着键鼠语音都是输入模态；长视界意味着从几秒走向分钟和小时。Grok Imagine 的视频扩展是第一步：普通模型用最后一帧续写会迅速劣化、且没有长程记忆（谁在说话、出现过什么物体）；他们的方案让扩展带着全部历史上下文生成——但朴素地把历史视频 token 全塞进上下文会爆炸，Cosmos 里 5 秒视频就是 5–6 万 token，50 秒就是 50 万（`00:48:34–00:54:58`）。中间态方案是 reference-to-video：上传最多 7 张角色/物体/场景图作为条件，不必携带超长上下文也能保持一致性——但他自评这是"作弊"，终极形态是模型自己学会选择性回看历史（他提到 Frame Pack 这类按距离压缩历史的启发式，并预言会被模型内化的机制取代）（`00:55:51–01:02:31`）。这条线索最后接回了 LLM：上下文管理、持续学习、"模型自动感知并管理自己的上下文"是语言与视频两侧共同的前沿（`01:34:16–01:36:58`）。

### 生成式 UI 与视频 Agent：黑药丸的推论

节目最超前的部分是他对生成式 UI 的严肃对待。Flipbook 这个爆款 demo 在他眼里不是玩具而是终局预览：一个浏览器，所有界面由生成模型实时想象——"想象互联网不存在，你输入 google.com，模型该给你看什么？"他的推演是：编码模型写代码、代码渲染像素，为什么不让用户意图直接到像素？diffusion 做前端、确定性系统做后端；人类对视频的输入带宽与对说话的输出带宽都是最大值，"说话给 AI、AI 用生成式 UI 回你"是 Neuralink 之前的最优交互（`00:22:10–00:28:17`）。Neural OS（用视频模型模拟整个操作系统、能玩 Doom）则展示了一个反直觉性质：模型在现有屏幕录像上训练，却能想象出从未存在过的界面——分布外泛化在生成场景里成了特性（`00:28:17–00:30:43`）。

然后是那颗黑药丸："视觉智能大部分来自语言。"扩散模型技术成熟后，每次视频模型的可感知提升主要来自语言侧——Cosmos 里视频扩散模型只有 7B，而提示词改写器是一个更大的 LLM（Llama/Mixtral 级），负责把"一只猫"这种字面指令扩写成详尽描述；"GPT image 生成一张图要三分钟，大部分时间在思考而非画像素"。prompt rewriter 还在进化成 Agent：要生成"今天的新闻"图，它会先去抓新闻、消化、排版再生成（`01:13:31–01:17:02`）。推论就是视频 Agent：语言模型把生成模型当作工具之一，与 Photoshop、FFmpeg 等确定性工具组合，通过长思维链迭代精修到生产级——"这和人类创作艺术没有区别，我们也不直接生成像素"。Grok Imagine Agent beta（无限画布上自动规划→生成→编辑→迭代）是第一次尝试；用户让视频编辑模型"把视频剪成一分钟"曾被认为是误解了编辑功能，在 Agent 范式下反而是合法请求（`01:19:00–01:24:22`）。他的时间预测：年底视频 Agent 的产出达到可投放广告的生产级质量，企业预算涌入，之后指数增长（`01:29:18–01:30:35`）。

### 离职、LLM 的下一个前沿与跨方向职业观

Ethan 离开 xAI 的原因与那颗黑药丸一脉相承："视频模型的瓶颈在语言与 Agent 部分，所以我想去做 LLM。"他给语言模型预测的下一步是上下文自感知与自管理：模型应当知道自己接近 80% 上下文、应当接管现在由 harness 启发式完成的时间注入、工具结果修剪与压缩——"从经验看，启发式工程最终会被吸收进模型本身"；更远的想象是模型能读到并修改自己的 agent harness 代码，"在测试时在线给自己编程"（`01:32:38–01:38:02`）。回望职业路径——与 ResNet 作者做识别与压缩、FAIR 做自监督、NVIDIA 做 Cosmos 与跑出 40% MFU 的 Megatron MoE、xAI 做更大规模——他的建议是 ML 内转方向比想象的容易："训练大模型的核心原则大体相同，别让'我是 CV 人'的自我设定困住"（`01:38:43–01:41:51`）。
