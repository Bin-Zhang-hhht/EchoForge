## 速读

嘉宾是 SemiAnalysis 的 Doug O'Laughlin——老网民可能记得他匿名时代的 ID：ValueMule。他的职业故事是一条"自找的支线"：2018 年研究 ASML 被半导体"nerd-snipe"，从此相信摩尔定律已死、旧剧本作废，2020 年写下他最满意的文章《GPT-3 与墙上的字》——"需求因 scaling laws 暴涨，供给因摩尔定律卡死，利好半导体，NVIDIA 几乎是唯一赢家"——后来与"全世界唯一和他一样半导体上头"的 Dylan Patel 共创 SemiAnalysis。让他至今震惊的不是方向对了，而是幅度：NVIDIA 成了全球市值第一。

本期双主线。其一是 Claude Code 如何吃下金融信息工作：他在假期里被 Opus 4.5"什么都开始一发命中"惊醒，从此把 SemiAnalysis 的招聘 case study 当基准、把个人持仓管理交给 agent、用 BigQuery 抓取 Claude Code 署名 commit 做出那张"占 GitHub 4%→5%"的疯涨曲线图，并断言"Excel 和 Bloomberg 是分析师的 IDE，它们都死了"——因此微软是全世界最有可失去之物的那家，而 Oracle 则把这场资本周期玩成了债务市场的 own goal。其二是他本行的硬核拆解：HBM 对 DRAM 约 4:1 的产能换比、上世纪 90 年代级 shortages 后无人投产能、洁净室两年建设周期、"AI 交易里最确定的一条腿是做多内存产能"，外加一个"CPU 短缺"阴谋论——COVID 采购潮到寿命 + Claude Code 让软件产量暴涨 + RL 环境吃 CPU。

## 主题正文

### 从 ValueMule 到 SemiAnalysis："摩尔定律已死"的一次下注

Doug 的半导体启蒙不是导师，是 2018 年的一次自我 nerd-snipe：做质量型价值投资的他研究 ASML 后"爱上了它"，顺着光刻机读课本、读整个下游，还把 Asianometry 的全套播放器当宝贝——"半导体从来都是科幻小说，每天造出一颗新芯片这件事本身是科幻，只是所有人都习以为常"（`00:03:46–00:07:43`）。他自认的"激进时刻"是真心相信摩尔定律已死：旧世界的前提是"成熟行业、合并、低增长、硬件不值钱"，而一旦科幻终结，所有白送的性能红利消失，定价权回到"知道怎么造好芯片的人"手里——NVIDIA 是最好案例：从芯片、网络、设计到 scale-up 全链都在自己手里（`00:07:43–00:08:23`）。2020 年他把这个判断写进《GPT-3 与墙上的字》——scaling law 拉需求、摩尔定律卡供给、并行计算崛起——结论是"NVIDIA 几乎是唯一受益者"。他说这是自己最好的长线预测，但真正让他后怕的是幅度："NVIDIA 成了全球最有价值的公司。就算读回我自己写的文章，我也不会把这两个事实连起来。"

认识 Dylan Patel 就是因为"全世界只有他和我一样半导体上头"——两人在 DM 里对骂，见过一次面，背景互补：Dylan 技术优先，他金融出身（`00:09:23–00:10:04`）。他把 SemiAnalysis 的商业模式反着讲了一遍：卖方研究是"三四十年投行体系的孩子"——IPO 要有人讲这个故事、评级要"半独立"——监管变迁后这套模式已是"四十岁高龄、弥留之际"；SemiAnalysis 不做"一分钱 EPS"的机械维护，只关心"技术变化如何冲击一切"：AMD 的 Helios 机架是否准时出货、能不能在某天开始产 token，这种拐点的时点与幅度值几十亿美元的收入差（`00:17:19–00:18:53`）。他给自己总结的方法论：一直擅长趋势——2019 年就痴迷 TikTok——"当你看到一个大浪且极有信念时，值得 all in，我围绕它重组了我的人生"（`00:11:27–00:12:00`）。

### 12 月 27 日的顿悟："你可以直接把事情做成"

他其实是圈内最早把 agent 当基准的人之一：SemiAnalysis 招金融分析师有一套多步 case study（"给这家公司做分析、按这个格式交回来"），他从 Claude Code 面世起就把它跑进各种 agent，想看"它们什么时候能一发命中人类要干 24 小时的活"，并且早就放话"它们会先超过最差的应聘作品"（`00:13:46–00:14:54`）。Opus 4 时代的 vibe coding 仍然费劲：要大量反馈、常出错。转折点他记得很清楚——12 月 27 日前后，圣诞假期、未婚妻身体不适，他一个人有空，正好赶上用量翻倍的活动。Opus 4.5 "开始一发命中所有东西"：MVP 一发成型，再让它改进、解释自己在干嘛。"某种能力阈值被跨过了，这和以往完全不同"（`00:14:54–00:16:24`）。

由此进入他现在的日常：把持仓和笔记粘给 Claude Code——建组合、跑基础风险、再"给我的投资风格做一个框架，给所有持仓打分、互相攻击"——"这是一个能迅速把我的思维方式系统化的工具。还能干什么？答案是什么都可以。我在播客里的笑话是：现在全都是 skill issue。"（`00:21:04–00:22:01`）那张著名的 Claude Code 占 GitHub commit 比例图也来自一次十分钟的直觉："听说 Claude Code 会在 commit 上署名？Claude Code，把所有 commit 都爬下来。"——BigQuery 每日拉取、cron 每天更新，曲线一路涨到 4%（他说现在约 5%）。"我喜欢看指数曲线，从没见过这个速率的。"他甚至把"读 70 本可视化书籍提炼成 90 token 的 skill"这种事当成理所当然——"token 是免费的，70 本和 3 本成本一样，谁在乎？"图表全部换成 Matplotlib 风格，"新图比旧图好看，信息速度更重要"。他的口头禅就此诞生：**"You can just do things."**（`00:22:28–00:25:23`）

工程层面的经验之谈密集落下：他喜欢 rubric——"我在乎 X/Y/Z，十分制打分"——可以压住随机性；rubric 和任务同窗能让模型自迭代，但分开跑更好，因为"每个上下文窗口都是全新的一眼"，混在一起会被 Opus 4.6 的讨好型人格带偏（"它超爱说好的好的我这就办"）（`00:26:13–00:27:16`）。context rot 是真事——"500 万 token 之后就该把它人道毁灭了"（他引了《人鼠之间》的梗）——所以他用新的百万 token 窗口"一个 compact 窗口里干完所有事"：CLAUDE.md 和 skills 的占比变得微不足道，"oomph 大得多"；subagent 各有各的窗口，compact 只是"把噪声开始压缩"（`00:27:26–00:28:51`）。

### 当编码 Agent 爬上信息工作的食物链

他的核心论点借用了一条老推文（Brian Hobart）：编码和金融是不同类型的抽象，但都是抽象——"Excel 是一个巨大的抽象，你在描述你认为一个金融资产值多少钱。说实话编码更难。而你告诉我难的那个被自动化了，为什么简单的那个不能？"所以 Anthropic 生产流量报告里"软件工程 50%、下一个是数据分析"的分类法在他看来是误读：数据分析是下游——"软件工程在芯片下游、AI 下游；代码是机器与世界交织的地方，是用来解决其他一切的出血前沿语言"（`00:29:31–00:30:03`）。具体产品判断同样尖锐：Claude for Excel "比 Claude Code 用 Python 加 Excel skill 再存回去差远了"——"为什么要给马车装汽车引擎？Excel 的抽象是人类格式化给人类看的；该操心的是面向机器的软件消费。我不需要再做 PowerPoint 图表，它直接把 Matplotlib 图像存给我就行。"（`00:30:03–00:31:11`）

swyx 提醒他"你们在变成 Bloomberg"，他顺势把矛头对准了所有分析师工具："Excel 是分析师的 IDE，Bloomberg 是分析师的 IDE。我相信这些 IDE 全都完了。我学 Bloomberg 那会儿要看视频学随机子文件夹和快捷键——这种隐性知识，马车时代才需要。一个能完美检索和分析信息的 agent，会拿出一个没有历史包袱的更好 UI。微软是最辣的那口预言：Excel、PowerPoint、email 是为人类信息工作设计的可泛化抽象——我认为它们不再重要了。Claude Code 或 Cowork 会摧毁那部分你每年都坐在那里干的信息工作。这不是分析，是我的胃在说话：我已经经历过那个时刻——**我再也不会在 Excel 里画图了。**"（`01:09:41–01:11:33`）swyx 的注脚是他自己的第一次创业 Sentieo——一个未遂的 Bloomberg 杀手——以及他当年的结论：彭博其实是三样东西，IM、顶级的新闻、数据源，"UI 从来都不是护城河"。Doug 在 SemiAnalysis 内部正努力"把 Bloomberg 拆出去"——"API 加 Claude Code 是我信念里的未来：可信的数据源、可扩展。交易员没戏（有场外信息网络、受监管），投行没戏，但作为分析师，我这一次是真的不在乎了——IB 的边际价值已经被它的笨重抵消，我只想快点画图。"顺带省下一年一两万美元的订阅费（`01:12:34–01:13:29`）。

### 微软的野蛮人难题与 Oracle 的债务 own goal

于是引出他"最辣的辣条"：微软是全世界最有可失去之物的公司——"它是横向软件公司，人类用它的软件做信息工作。我画不出更大的靶子了。"而 Azure 与 OpenAI 的关系是"雇野蛮人守城"：古罗马花钱请野蛮人看门，他们一年比一年强，总有一天会说"我们把这几堵破墙拆了吧"——"这就是 Google-Yahoo 的故事重演。而且你只能二选一：要么 all in Azure 当哑管道（电信时代的 Charter），要么停下 Azure 投入、回头抄它们的功能修城墙——但股价全押在 Azure 收入上。如果给微软 ex-Azure 估值，倍数会非常难看——上一次这么便宜还是 Steve Ballmer 时代，直到 Azure 和 Office 365 让它翻身。"（`01:21:15–01:24:02`）Satya 的"负责任"在他看来正是创新者窘境：最大化当期股东价值，还是相信 AI 会杀死核心业务并赌上公司？"Satya 不是信徒——他不 ASI-pilled，觉得这是新的 Lotus/Excel，一个新工具而已。财报电话会里'我们可以增长更快但选择再投资内部能力'的翻译就是：不再雇那么多野蛮人，回头修墙。他们开始内部训练、做基础模型、用手里有权重的 MAI——我非常怀疑，因为他们的执行一直惨淡。2023 年那笔大交易时我们都以为微软赢麻了：有分发、有完美产品。现实是 Claude for Excel 就是它该有的样子——**这本来该是微软做出来的东西。**这才是山头那边的部落，夜间突袭就能把城堡洗劫一遍。"（`01:24:43–01:26:58`）

Oracle 则是"不负责任"的反面教材，而且错在执行不在方向："该接下 slack，但整个 setup 是 own goal：毁了信息发布，毁了融资。门一开就喊出 4000 亿美元 RPO，把牛吹满，然后拼命融资——这是他们第一次做这种规模的 buildout，于是延误来了，资本主义说踩踩刹车。正确的做法是分级释放、管理预期，让已部署 GPU 的收入部分自融资，走一条 glide path，而不是 up-down-up-down 的大爆炸。真正炸掉他们的是债务端：投资级 TMT 债大概 5000 亿，Oracle 一家占约 1350 亿——每次巨型新发债都要给人理由买你的而不是别人的，整个指数被供给砸得抛售，CDS 市场恐慌，很大程度是机械性的供需问题。这是一个我从没想过的瓶颈：**债务的供给**。资本主义消化不了这种量级的资本需求——超大规模厂商历史上完全自融资，从没发过债，第一次开口就是要 100 亿美元授信。 Oracle 是往一个流动性很差的市场里 super jolty 地猛加，我会说他们付得起，但这操作太糙了。"对比之下微软"本可以完全内部融资，融资成本跟美国政府一样低，评级就值两个点的资本回报率——不这么做我都不知道为什么"（`01:27:12–01:31:20`）。他反复声明立场："新信息来了我随时改口。"

### Agent 团队、蜂群与内存危机的雪崩链条

Claude Code 的 agent team 在他那里得差评："我有个争议观点：Anthropic 没给 agent team 做 RL——纯提示词的实验，真的很差。"但 agent swarm 让他眼前一亮：他用它做了"把同一组题做 20 遍、量性能差异"的内部基准——"三个月前这完全超出我一个普通人的能力范围，现在完全可用。Kimi 2.5 的 swarm 确实有意义地提升了性能，agent team 则意义地变差。我喜欢 subagent：干净地领任务、回来。"他看过 Anthropic 训练 agent team 的论文——"跑那个 swarm 要 16 节点 H100，我们俩都跑不起，但那是下一个方向的信号：单个 agent 爬到头之后，就是多少个 agent 连成更大的链条——把推理问题 scale out。这要求上下文不发疯、token 效率够好"（`00:32:12–00:35:26`）。OpenClaw 他玩了一晚上就退了坑："让它读我所有邮件和日历，爽了一晚上，然后我反应过来——这东西真的、真的、真的容易被提示注入，而我接的是很重要的东西。Claude Code psychosis 对我来说够用了。"对"这不就是 Zapier 吗"的质疑，他的反驳很金融："Zapier 也能到完成态，但你要点八个小时的按钮、复制粘贴、保安全；Claude Code 四分半钟到完成态。早到但错了没关系，关键是机制——这条历史在计算行业里一再重演。Zapier 被自己的笼子关住了，swyx 说得对：你的先验会变成你的监狱。"（`00:36:19–00:39:44`）

他的 Claude Code 配置哲学是"少即是多"：几个基础 skill、大量 API（包括把 SemiAnalysis 的信息做成内部 API，让每个研究员有基础上下文——"上下文才是关键"）；hooks 被低估但只用在 skill 调用上；早期玩过 Geoff Huntley 的 Ralph loop 那套——"是多轮自动化的预兆，但保真度还不够，别搞疯狂多轮"。最佳实践："每个会话开头先问清楚目标，在单个上下文窗口里收尾"（`00:39:45–00:41:25`）。最能体现工作方式的是那个周末项目：微调时序基础模型预测 NAND/DRAM 价格——收集一切信息、选 Kronos 2（因为有协变量）、agent 用 Serper/Exa 搜资料、另一个 agent 处理价格数据的不完美、自动挑按小时租的 GPU、迭代循环——结论是"这条路大概率不通，因为 regime 乱得一塌糊涂"。swyx 借题发挥警告玩 LLM 炒股的年轻人：宏观转向时规则会完全反转。但项目留下了真东西："我把能找到的所有内存价格、付费 API、增强数据源、所有协变量都聚合齐了，下一步让它给历史上每一次内存周期写'开端-中段-结局'的摘要并做成仪表盘——今天应该就能完工。我是写内存周期最多的人，当年人类做法是啃旧年报、串叙事、查每年的 GDP——那是毕生工作量、一个博士项目。**我干了一天，两天。**"（`00:41:30–00:45:18`）

对"没有专家信息你怎么审这份报告"的质疑，他给出的框架呼应了开场白："这玩意儿一直都在犯错，它还是个初级分析师。人类世界里初级分析师干够多年会产生元学习——知道哪类分析自己是专家、命中率稳定。我不认为模型的元学习到位了，虽然花一万亿美元的所有人都赌它会到位。但对专家-filled 的公司，它是所有专家的巨大放大器；对新人的使用我们会更不宽容——slop 一眼就能看出来，slop 且无认知就不行，**手工的最后 5% 才是关键**，而我天生知道那 5% 是什么，指哪儿改哪儿。今天仍然有人类在环；某天它会超人，今天没有。"他甚至宣布自己“AGI-pilled 了”——按"自动化多数常见工作"的定义："让一个 22 岁的入门数据分析师跟一个像样的 agentic 系统打，会被杀得片甲不留。那个工作看起来确实危险。4.5 的能力让我们 agentically 够到了某个能做更大信息工作的水平——那一刻我想：好吧，这改变了一切。"（`00:45:55–00:49:38`）他给同行的推演是：自己是 bleeding edge 采用者、聪明、评估过工具——"这工具我会从我的尸体冷手里撬出来"——那么大多数足够像他的人都会跟进；"24 个月内，Claude Code/Cowork 会成为一切信息工作的基线。"他的"Claude Code 时刻"对标的是当年的 GPT-3.5/4：明知它编了点东西，但比人肉搜索几小时强。swyx 的补充一针见血：人类只有一次出手机会，agent 可以并行三次——"复审过程就是思考，你要变得擅长 review，或者说擅长 hygiene。"而 Doug 的担忧收尾："我的专家判断是智能手机出现前炼成的。没付过人类认知的人，不会成为好的 reviewer——因为你知道哪条该覆盖哪条，那是学来的经验。只做审查的人，永远不会把那些假设嵌进自己的判断里。这是个真实的危险。"（`00:51:12–00:55:43`）

### GDPVAL、通缩异说与铁路资本周期

两人对齐 AGI 定义时搬出了 GDPVAL：覆盖约 2-5% GDP 的白领任务基准，50% 即与行业专家打平——"GPT 4.0 到 Opus 4.1 涨了一截，5.2 和 Opus 4.5 已经越线，现在七十多——模型在稳定的超过行业专家。这就是 AGI 的定义吧？"Doug 同意：白领知识工作无聊但巨大，"曾经 90% 的人务农，今天不到 1%——技术会大改这一切；也许人人休闲，但迄今为止我的经验是：所有人只是更拼命工作了"（`00:57:54–01:00:01`）。swyx 的宏观分层（农业→制造→白领→金融，层层递减、新层涌现）引出"第五层"信仰，Doug 接得很快："人类是我学到的最惊人的东西——每个纬度都有人。我们肯定会发明新工作，只是 5-10 年的间隔就可能天翻地覆，而它正在我们的一生里、此时此刻发生。"（`01:00:49–01:01:06`）至于 AI 为何还没显现在 GDP 里，他贡献了一个自认"疯子理论"的辣条："万一 AI 是极度通缩的呢？GDP 是战争年代发明来算'能从经济里挪多少去打仗'的工具；信息工作的经济核算本质是服务除以小时，没有'件'的概念。如果信息工作真能拆成单位，工作量会暴涨——供给涨这么多，会不会直接通缩？"swyx 接："也许会有场'AI 大萧条'，然后我们想明白怎么用它。"（`01:01:37–01:02:47`）

回到他本行的资本周期，铁路是他的最爱：互联网建设全口径约一万亿美元（实际购买力），这轮已经远远超过；而铁路更疯——它是叠加在农业之上的第一层新蛋糕，"银行干脆是被铁路发明的：需要的钱太多，当年市面上 85% 的纸面证券 essentially 就是铁路债"——swyx 补刀"美联储出现之前，卡内基就是美联储"。那次周期横跨 45 年、三次繁荣萧条；这轮信息跑得快、周期会压缩，"但我很难相信一次走完——我的直觉是多轮：小铁路周期、大铁路周期，然后现代铁路从中诞生。当年铁路资本开支占 GNP 4.8%、占全社会固投 25%，持续了十年——我们正在正轨上，Stargate 一家就是美国 GDP 的 2%，加上 Anthropic、xAI，我们会超过它，这次更大。"至于钱从哪来："每一轮资本周期都会去中东找钱，这恰恰是泡沫的成因：'必须建，价格无所谓'——然后某天回头看：嚯，这价格真够呛。"（`01:03:01–01:06:23`）而需求端的实证就在他自己身上："Claude Code 第一次让我这种个人用户在狂饮。我在 Max 档，不够；有人在买五台 Max；我在 Fast Max 加百万 token API——成瘾级。这东西对我一年值两三万美元起步，我定不了价，完全不知道弹性。"swyx 翻译："你雇了个完全合规、能并行的初级分析师——9 万美元年薪那种，你能雇一百个。管不了一个年薪四万的初级分析师是 skill issue——但它才三个月大，就像第一个月不会用 iPhone，没人该骂你 rube。"（`01:06:43–01:08:11`）身处最前沿的乐趣是"看设计模式实时盛放"：SemiAnalysis 一位经历过整个科技史的老同事（他喊他 Tanj）讲过早期互联网连"浏览器会不会赢"都不确定，大家在找"远程网页文件服务"这种设计模式——"我们现在又到了那里，所有设计模式都开着，我们将集体商量出 hygiene、抽象层次、SaaS 会被颠覆多少——谁知道呢。但你有前排座位。"（`01:08:14–01:09:20`）

Codex 部分他完成了一次公开的自我修正：作为"前 Codex 黑子"，他写过 SemiAnalysis 那批 token 效率与 context rot 文章，结论是"Anthropic 赢在 token 效率"——然后 Codex 5.3 出了，"那完全不再重要，他们回来了。Codex 5.3 在编码上真的牛。"但用法分化依旧："Opus 4.6 我拿来干广义信息工作；Codex 被 RL 调教成 SWE-Bench 机器，你让它去搜网站，它给你写个爬虫——别！直接把网页 token 吃进去啊。它 coding-pilled 到不可泛化。"bloomberry.com 的榜单上 Claude Code 领先，但他承认口径问题：Codex 只在 PR 上署名，like-to-like 比例更接近；"我赌他们下一次带新预训练的 RL 版本发布时天平就翻过去——5.3 的 RL 栈太强了。"至于榜单第一的 GitHub Copilot，两人互相打趣"那是旧金山泡沫的视野"——"Windows 用户有十亿 ARR 呢"。对 Conductor 这类"同时用两家的中间件"，他搬出 IaaS/PaaS/SaaS 的老故事："PaaS 永远死在中间，被两头吃掉。但此刻我同意——让它们互相 review、互相吼，挺好。"（`01:13:29–01:20:31`）

### TPU 的窗口期与内存的雪崩

TPU 外售话题他给了一个精炼的战略解读："Sergey 不想输。Gemini 3 之前的想法是囤积所有 TPU——可是产品端被按着打，囤着有什么用？我们写过 TPU v8 的分析：Ironwood/v7 是 NVIDIA 与 TPU 之间 TCO 差距的峰值。在你最强的时刻，要么挤利润，要么抢市场份额——跟 Anthropic 的外部合作就是抢份额。TPU 在 Google 内部的价值，我算过，假设拿到 30% 份额，约一万亿美元——人人都在撬 merchant silicon 的护城河，而原 TPU 团队早散落到 OpenAI、Meta 各处，差距会随时间收窄。第二名的宿命你从 AMD 就看明白：没装机基础的芯片没人升级。现在 TPU 软件生态成熟、硬件成熟、网络成熟、还有一个会用的外部大客户——要抢份额，就是现在。"窗口的物理边界也说了：Rubin 会更有竞争力，"技术原因是 HBM，HBM4 对 3；NVIDIA 一贯把芯片攒成 F1，TPU 是超大库里高稳定的可复制 pod——GB200 若按时且稳定，早就碾压 v7 了。供应链上 NVIDIA 独一档：HBM 涨价你以为也会砸 TPU，Jensen 亲自在亚洲跟 SK、三星、台积电挨个喝交杯酒——你以为他为什么喝酒？他要拿芯片。Sergey 可没去台湾喝酒。"结论："TPU 有限供给，NVIDIA 锁死整条供应链、拿到最好 HBM、第一个上更高机架密度——等 Rubin 把内存和 scale-up 一起 jam 满，这个窗口就关了。当前最大的 blocker 是台积电。"（`01:31:29–01:39:07`）

随后是全场技术含量最高的内存拆解（源自他的"Memory Mania"文章）：HBM 与普通 DRAM 之间约 3:1 到 4:1 的产能换比——"我写过一篇叫 super oil 的东西：发明了一种更高级的航空燃油，唯一的造法是把你所有其他燃油全部凝聚精炼掉——于是这边任何需求都是即时短缺。"剧本三层叠加：刚走出史上最惨的 NAND/DRAM 熊市（"上一个可比的要回到 96 年那种历史级"），厂商自由现金流为负、破产边缘、零投资——洁净室和设备是三年 lead time 的东西，没人买；HBM 需求又像上帝下凡，每一 bit 等于 4 倍 DRAM 产能；KV cache 卸载还把中间层（DDR）一起蒸发。"我们的结论：DRAM 价格还能再涨 100%。再涨 100% 之后会开始出现需求破坏——超大规模厂商在边际上少买（'要不我们先搞能源？'），讽刺的是美国大多数数据中心都在延期，12 个月的工期变 18 个月；于是你先加倍三倍下单把 pipeline 拉满，内存厂看着需求狂喜，等你发现电力才是约束、把订单冷静下来——历史上那就是内存危机、价格崩盘的时刻。看总需求和电力购买的缺口，这缺口大得离谱。**这轮 AI 交易里逻辑最顺的一条腿就是做多内存产能**——SK 海力士、美光、所有半导体设备。"这甚至波及你的口袋："等 iPhone 进入现货市场，价格要涨 100%。要买趁现在。"连死技术都还魂了：CXL 内存扩展——云计算时代想给 CPU 挂弹性内存池、被 HBM 碾死的技术——"现在因为内存太缺，把 DDR4 老芯片全插进机架用 CXL 挂上去——死 technology 获得了一次门前补射。"（`01:39:28–01:45:16`）

swyx 由"上下文窗口两年停在 1M"推论"五年十年内不会到一亿 token——这就是天花板，因为 DRAM"。Doug 顺着历史的惯性给出商业设计："按上下文配给：免费版给你 1000 token 的窗口，再为百万上下文收 100 倍的钱——百万上下文就是豪宅，你现在就住在豪宅里。"swyx 当场命名"context rationing（上下文配给）"。Doug 的反问也值得记录："论文里长上下文的实际利用率是衰减的，一亿上下文如果不能被用满，它重要吗？"swyx：今天的一亿 token 方案都存在、但各有各的不行，不是全注意力；算法侧会继续改进，但物理约束是软件永远翻不过去的山。RLM 式的递归语言模型（复用同一窗口）他说"很感兴趣，但我一个做半导体的懂个屁"。Talos 式"把权重烧进芯片、不需要内存"的 ASIC 他认为"说得通，来得正是时候"——毕竟生产模型"都被蒸馏得不成样子了"，只要烧进去的是效率 Pareto 前沿上的那档，就能无限 scale；市场也确实在分叉成"性能推理服务"与"训练/大生产"两半。至于为什么 Etched 们没先做到——"他们赌的是大 systolic 阵列，即一切 compute bound；可今天的生产瓶颈明明在内存上。AI 加速器我命中率高的原因很简单：我不信它们，直到 Cerebras 和 Groq 之前全是失败案例——SambaNova 倒是有点意思，但全是交易问题。"（`01:45:19–01:51:13`）

最后的"阴谋论"时段献给了 CPU："你有没有发现最近 web 服务特别不稳定？不只是 AWS，不只是 GitHub/Azure——所有云都在出事。两个嫌疑：一是 vibe code slop 上生产；二是我这个趋势脑的猜想——COVID 期间 2020-21 年大家买了约 1000 亿美元 CPU，现在正好到五年寿命的更新周期，但所有人的预算都被刮去投 AI 了，CPU 只做维护性 capex。讽刺的是 Claude Code 恰恰在制造新软件——软件总得跑在 CPU 上；RL 环境要模拟软件、狂吃 CPU；生产 agent 再加一条斜率。两年的投资不足之上叠一个小斜率——boom，短缺。我觉得我们可能真的在经历 CPU 短缺。"swyx 笑称"半导体佬的结论永远是半导体数字上涨"，但他认真收尾："内存价格涨到我们必须做选择——低端手机、游戏显卡，历史上内存从没这样把人直接挤出市场，这是很多年来的头一遭，接下来怎么消化会非常好看。"（`01:51:13–01:54:33`）

### 写作、睡眠与大陆分水岭小径

收尾回到个人。他的第一天赋是高速阅读——"小时候疯狂读书；朋友拿了博士，我去读他的论文，就能说出个大概"——当年啃半导体教材就是"生吞"。写作闭环了阅读：从 2021 年 10 月起每周一篇 Fabricated Knowledge，连续了很长时间（SemiAnalysis 加个人 Substack 之后偶尔断更）。LLM 在他的写作流里只当下游："我不喜欢 LLM 写作，但喜欢它做 ideation——把乱七八糟的想法整理成带要点的提纲，我读着提纲并行构思和写作。"他把《On Writing Well》整本做成了编辑 skill。没有选题库，"一次成型"：想法在脑子里滚够久、烂提纲成形就动笔；预写作大都在 SemiAnalysis 的 Slack 里"用时再搜"。他的一号写作建议带着 agent 时代的韵味："做完预写作、想清楚、去睡觉——**早晨全新的上下文窗口**是我最好的建议。写不出正文时就把提纲列完去睡，早上开个新标签页直接写，一觉能到六七成，剩下的顺着填。"（`01:54:37–01:59:14`）

最后是 2021 年、GPT-3 文章之后的那次出走：用四到六个月独走大陆分水岭小径（CDT）——美国三大长距步道中最长最偏远的一条。"我选了最吓我的那条：如果这辈子只有一次机会，我要做最像'我完成了我想做的事'的那件。错过了 Substack 增长大年？我过得挺好。六个月、约 2850 英里、大部分时间独身，有声书听到讨厌、音乐听到讨厌、无聊到发霉——你把一切都经历一遍。它没有让我'长大'，但让我对自己的认知更清晰：我知道自己如何反应，我知道我那条'再也不会往前一步'的线画在哪。它是浓缩的高浓度人生。所有这些 AI 话题都太抽象、假得很——人类演化是为了在泥里讨生活、狩猎采集、别死掉。回到马斯洛底层走一遭：最低的谷和最高的峰，'这一切有什么意义'和'活着真好'。我建议年轻时去，最好大学一毕业就去——**自我掌握是你最重要的工具**。"（`01:59:14–02:03:44`）
