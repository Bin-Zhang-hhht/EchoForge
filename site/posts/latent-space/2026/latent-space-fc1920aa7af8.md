## 速读

Latent Space 与 Redpoint 的 Unsupervised Learning 第二次年度联动，swyx 与 Jacob Effron 盘点了 AI 工程过去一年的全部主战场：Claude Code 一年做到约 25 亿美元 ARR 的编码战争、"Agent lab"的自训模型剧本、skills 成为 Agent 的最小打包格式、以及他对 2026 的论题——编码 Agent 将冲破编码的边界去做其他一切。

最值得带走的三点：基础设施终于出现稳定性征兆——skills（一个 markdown 加脚本）可能就是最小可行打包格式；"dark factory"（零人工评审直接合入）是继"零人写代码"之后的下一个前沿，也是唯一可扩展的路径；记忆与个性化是最慢的缩放因子，也是下一个大战场。

## 主题正文

### 会议议题表就是时代精神快照

swyx 刚从 AIE Europe 回来（现在大约一季度一届，"跟上 AI 的速度"）。他策划的议题表暴露了当下最热的三件事：OpenClaw 是过去四五个月的故事；harness 工程与 context 工程是两个相关的 Agent/rag 主题；剩下是 evals、可观测、GPU、LM infra 这些常青树，加上多模态与生成式媒体（`00:01:17–00:02:13`）。对 LangChain CEO Harrison Chase 那条"AI 基础设施终于稳定了"的推文，swyx 的态度是半信半疑但乐观：大家尝试了无数种给 Agent 打包集成的方式，最后落在 skills——"一个 markdown 文件加一些脚本，我想不出比这更简单的了"。如果共识收敛到"Agent 就是带工具循环和文件系统的 LLM"，那稳定性论成立；但他拒绝押上名声——"如果又变了，跟着变就行，没关系"（`00:02:49–00:04:33`）。基础设施工具的残酷在于客户是挑剔的开发者且"转向很彻底"，而应用公司（Sierra、Lovable、Abridge）反而稳——你是客户的外包 AI 团队，负责把最先进的 AI 方法应用到终端，无论工程层怎么变这个位置都成立。水平方向真正的新东西是"经典云的 AI 时代再发明"，头号代表是沙箱——"说到底它是另一种 compute，别太激动，但工作负载是巨大的"（`00:04:33–00:06:39`）。

### Agent Lab 剧本与自训模型的反转

该不该自训模型？swyx 的答案是"Agent lab 剧本"：从大实验室的 SOTA 模型起步、为领域特化，等工作负载与高质量数据攒够后再自训模型——省成本、省延迟，外加一个"起个花哨名字发点研究"的营销红利（`00:06:39–00:07:38`）。这是真实的还是营销？他的证据是自由市场检验：Cursor 的 Composer 2 与 Cognition 的模型在没有补贴的模型选择榜单里都进了前四五名。更重要的是它代表了苦涩 lesson 的反转：先在通用大模型上 bootstrap，等工作负载变得"量大而方差小"之后，蒸馏成小模型自己跑——完全说得通（`00:07:45–00:09:28`）。另一个态度转变是对非 NVIDIA 硬件：Cerebras、Groq 与"中间一大片"在过去一年被疯狂抢购，推理速度从每秒不到 100 token 到数千 token——"我过去觉得快两倍没意义，但每 10 倍会解锁一种新的用法模式；整个应用类别会一夜出现，谁也预测不了"。Cognition 用了 Cerebras，OpenAI 也是；他提醒这是多年投资周期，"别太快否定它"（`00:09:28–00:11:25`）。

### 卖给 Agent：60% 的流量已经不是人

基础设施公司正越来越多地以 Agent 为买家。swyx 转述 Vercel CTO 在他会议上披露的数字：Vercel 管理 App 的流量里约 60% 是 bot 而非人类——"你的主要客户现在是 Agent 了"。生存法则被他压缩成一句话："如果它没有一个 Agent 能用的 API，它就不存在。"但更深的一层是：Agent experience 大体上就是好的 developer experience 的别名——好文档、一致的 API、无状态、可渐进发现，这些你本来就该为人类做好；至于针对聊天机器人的"SEO"，他不信，但承认短期红利真实存在且会复利。预训练数据里的赢家确实在复利（Resend 成立仅两三年，在"给我一个邮件服务"的默认推荐里占到约七成），这说明新玩家仍有入场机会，但"榜单不会给你 20 个位置，只有三个"。他预计下一个大转折是个性化与记忆："现在的选择只是提及频率，未来由记忆系统决定"（`00:11:25–00:16:49`）。

### 编码战争：25 亿美元 ARR 与"能力探索阶段"

编码市场的规模在一年内被重新定价：Anthropic 的 Claude Code 约 25 亿美元 ARR（确认口径有争议），OpenAI 大约 20 亿，Cursor 传闻 20 亿——"一年内凭空诞生的市场"。当前阶段是 capability exploration：token-maxing 的行为被奖励而非惩罚，"我们还没进入效率阶段，谁更疯狂、更有创造力，谁获得相对奖励"。他引述 OBI 的 Ryan La Popolo 每天烧 10 亿 token（按市场价约每天 1 万美元）的例子："大部分可能是 slop，但如果出现新能力，他会比你先发现，因为他在试而你没在试。活在边缘的人才会发现下一个热点"（`00:16:49–00:21:41`）。定价策略也成了武器：Anthropic 是高价限量甚至限制模型发布的玩家，Codex 则敞开 SDK、重置限额、大方补贴，Gemini 同样——"在 Claude Code 或 OpenAI 的 200 美元月费上做能力探索，其实不亏"。

市场终局的判断是"现状最可能"：两个大玩家加一串满足其余用例的长尾。结构性变化需要 Microsoft 醒来动真格（"我们有 GitHub"）、Mistral（他在早餐会上被 Alex Wang 告知"别低估他们做编码的野心"）、xAI 或中国实验室（ZAI/GLM）发力——大家都在試，但过去一年格局相当稳。实验室扩张的方向是金融与医疗：金融的变现路径更清晰，医疗更棘手；而 Cursor 与 Cognition 反而因为专注编码留出了空间。大企业想要一个"不只是模型实验室"的专属伙伴——agent lab 的价值主张就是"最后一英里我们替你做"，与模型实验室的极简主义各擅胜场（`00:21:41–00:27:02`）。估值现象则打破了风投的传统估值带逻辑：xAI 的 ping 值 1.2 万亿美元，"每三个月都可能是一次生存级别的上行或下行事件"——Anthropic 曾被怀疑凑不够资本留在牌桌上，编码恰好命中、模型恰好合适、执行出色，转眼成为全球最有价值的公司之一（`00:27:02–00:28:27`）。

### 消费 AI 的平台期与"第一次魔法体验"的黏性

一个反直觉的观察：消费 AI 的 ChatGPT 不再增长，但那更多是品类问题而非份额问题——工具对知识工作者是魔法，对全球多数人还不是日用产品；编码却整体抛物线式上涨。有趣的是 Claude Code 的黏性：Codex 被普遍认为不遑多让，但第一个给你魔法体验的产品留住了大量用户——"第一印象的锁定超出了我的预期"（`00:28:27–00:32:12`）。swyx 补充自己的体验：Codex 仍在追赶，他喜欢的只有 Spark、skills 集成和速度这类小点，"几乎像是在说服自己"。真正的问题是：为什么只有两个名字？Gemini 和 xAI 的存在感在哪（`00:31:22–00:32:12`）。

2026 论题在此时抛出：OpenClaw 是未来的预览，OpenAI 与它有联想但不拥有胜利权。"2025 是编码 Agent 之年，2026 是编码 Agent 冲破遏制去做其他一切之年——编码 Agent 持续获胜，因为它们生成软件，软件吃世界，所以编码 Agent 吃世界。"（`00:32:53–00:33:30`）对"基础模型会不会吃掉创业品类"的经典问题，他按公司规模分层：极早期创始人不用怕——最差的结局是作为求职面试被实验室收编；中型创业公司要担心；LM infra 已在整合（Langfuse 被并入 ClickHouse 之类）；最危险的是低 NP 的传统 SaaS（`00:35:27–00:37:33`）。他自己就在亲历 AI vs SaaS 的内战：活动与赞助管理 SaaS 年付 20 万美元，理论上 2000 美元就能自建——"但我没法一个人拍板，得把团队带上来"。他看到每家公司内部都在上演同一场争论：AI 原生派嫌守旧派闭眼不看现实，守旧派怨 vibe coder 留下 80% 方案让同事收拾——"AI 原生的 system of record"（Convex 式的、AI 应用的 Firebase）还是一个空白（`00:37:33–00:40:01`）。

### 安全、巨型模型与记忆的慢缩放

在与 Anthropic CPO Mike Krieger 的晚宴上，别人都谈安全，swyx 提了 biosafety——"有人在家里就能制造灭世病毒，去读风险报告"；Krieger 的回应是 security 才是更大的问题，因为像 Mythos 这样的模型即使只给 40 家、每家上万人，也算不上私密——"里面一定有坏Actor"。他建议 Anthropic 调低营销调门："模型非常好，不需要那么多营销式声明"（`00:40:01–00:41:51`）。对 10 万亿参数级巨型模型，他的判断是配给制的暂时现象：未来三五年更大的集群对所有人上线，"两年后还会限供吗？不会——会限供的是下一阶段"。他的个人理论是 Google 的 Gemini Ultra 从未发布、只发 Pro 和 Flash，是因为 Ultra 被留在地下室当蒸馏教师——"任何实验室这么做都合理"（`00:41:51–00:43:02`）。而真正让人不安的是"上下文长度是 LLM 里最慢的缩放因子"：从 4K 到 1M 花了三年，Gemini 的百万上下文放了两年没人用——"记忆会是最 大的限制"（`00:44:13–00:44:50`）。

过去一年他改的两观：一是对开源模型转多——去年 Braintrust 的 Alek 说开源份额 5% 且在降，现在数字在涨（开放路由的选择数据即使价格调整后也在升），Fireworks 与 Together 大涨、fine-tuning 即服务复活；关键是要把"top 20% 的 Agent 初创"与均值公司分开看，前者明确转向开放模型。二是编码上的 360 度转弯引出了"dark factory"概念：第一级是零人写代码（五个月前在 Cognition 首次遇到），下一级是零人工评审——直接合入、不 review，OpenAI 正在探索。"听起来和当初零人写代码一样疯狂，但它是唯一可扩展的方式"，代价是把 SDLC 翻转过来：更多测试、更多自动验证——"本来就该做的事"。量变会带来质变，" quantity 帮你到达 quality"；2026 年的赢家不会是说"那是 slop 我不参与"的怀疑者，而是"这事儿不管有没有我都会发生，那我把它掰向正确的方向"的人（`00:47:44–00:49:36`）。RL 与后训练也比想象中重要：模型几个月后会被扔掉，但数据、工作流与领域改进留存；合成 rubrics、Doctor GRPO、多轮 RL（数百轮）意味着"RL 正在变得比人们以为的更加多轮、更加领域特定"——可以定制到非常窄的维度（`00:49:36–00:51:50`）。最后的展望是记忆个性化与世界模型——他引用 Fei-Fei Li 的空间智能文章："她可能还没有答案，但问题陈述是对的"；并以《心灵捕手》作结：LLM 就像读遍了所有书、无所不知却从未活过的 Will——"知道一切和活过一切之间的差距，正是下一个前沿要补的"（`00:51:58–00:54:21`）。
