## 速读

Latent Space 全新 AI for Science 频道第一期，嘉宾是 FutureHouse（非营利研究实验室）与 Edison Scientific（风险投资公司）的联合创始人 Andrew White——前罗切斯特大学教授，ChemCrow、PaperQA 等科学 Agent 的作者。他从分子动力学 PhD 一路讲到自动化科学的最新进展 Cosmos，穿插了为 GPT-4 做红队、进白宫汇报、以及"模型黑客出六个氮的化合物"的一手故事。

最值得带走的三点：Robin 论文的关键发现——专家评委最看好的假设并不是最终实验成功的那个，这让他"对验证器在环（数据分析、文献检索、单元测试、真做实验）的信心远超人类意见"；Cosmos 的核心是世界模型——一个随实验不断更新、可做出预测的"信息蒸馏体"，类比编码 Agent 的 Git 仓库；以及那记对过去的自己挥出的重拳："分子动力学被高估了，DFT 可能更被高估"——AlphaFold 用 X 射线晶体数据、在桌面 GPU 上击败了烧掉数亿美元专用芯片的 First-principles 路线。

## 主题正文

### 从"无关的计算机人"到自动化科学

White 的职业轨迹是一部"总是太早"的历史。华盛顿大学 PhD 期间，他在一个 19 人做实验、2 人做模拟的组里研究分子动力学与非黏附材料（植入物引发的异物反应——心脏起搏器因胶原包裹反而好换电池，血糖传感器与脑机接口却因此报废）；博士后做最大熵方法——"机器学习的逆运算：用复杂模型拟合很少的观测"；在罗切斯特大学建组研究多肽"四五年，当时没人在乎，现在多肽是最热的东西，我听说前阵子还有多肽锐舞派对"。2019 年 UCLA IPAM 学术休假的经历（LeCun、Frank Noé 在场、Terence Tao 来访）让他转向机器学习+化学，写下教科书级的讲义，因为"化学全是图、对称性与几何，当时的 ML 课只教到 RNN 和图像分类"（`00:03:02–00:08:02`）。转折点是原始 Codex 发布后他把 transformer 用于化学任务、写出"可验证奖励"基准（补全 MCMC 函数体+验证器）——"领先于时代"，相关观点文章引来 OpenAI 请他为 GPT-4 的化学/生物风险做红队——他比 GPT-4 发布早九个月就在用它（`00:08:02–00:09:20`）。ReAct 论文出来后他把 GPT-4 接上去，与 Philippe Schwaller 和 IBM 合作用 GPT-4 操作瑞士的云端实验室，加上一个"代理式 RAG"（这词当时还不存在，创意借鉴了 Harrison Chase 的博客）的文献研究 Agent——这就是引发轰动的 ChemCrow。论文被呈送到白宫总统的日程表上，国家安全顾问亲自讲解；他也因此见到了一堆"不想认识的三 letter 机构"："这会怎样改变炸药？""这会怎样缩短核武器研究的突破时间？"——"说实话我不确定。世界上真正懂 AI+科学的专家并不多。"（`00:09:20–00:11:34`）

FutureHouse 的诞生来自 Sam Rodriques（曾与 Eric Schmidt、Tom Kalil 讨论）的"聚焦研究组织"（FRO）概念：不在学术界、不在近垄断大公司里做科学。他们的决定是把使命直接定为"自动化科学"，而不是"看看 Agent 在科学里能玩出什么花"。随后他辞去终身教职（刚拿到tenure与 NSF CAREER 奖）："AI over science 在学术界很难做，终身教职加写基金不是你能对一个领域下的最大赌注。"Edison Scientific 从 FutureHouse 孵化，想把同样的事在更大规模上做——但他坦承 AI 研究与 GPU 的昂贵让"FRO 孵化风投公司"的模式可能难再复制（`00:11:35–00:14:24`）。他对自己的校准也很清醒："我在月尺度上高估进展，在年尺度上低估进展——2023 到 2025 年是巨大的进步。当年公告写'十年使命：自动化科学'，Sam 现在后悔写了；两年后我们有了 Cosmos，一切都快得多。"（`00:14:26–00:15:12`）

### "自动化科学"的定义与真正的瓶颈

White 划出一条界线：很多团队在用 AI 建模具体系统（细胞、蛋白折叠、抗体设计、虚拟细胞），而 FutureHouse/Edison 要自动化的是"科学发现的认知过程"——提出假设、选择实验、分析结果、更新假设与置信度、形成对世界的理解（世界模型）、再催生新假设。曾以为要从零建整套组织（自动化实验室、所有论文集中、一切套上 API），但模型变好后不断被迫停下重想："不用再手把手了；代理可以给 CRO 写邮件、告诉你要做什么实验，你拍个视频给它看就行。我们总是过度工程化——基本全都是过度工程化。"（`00:15:54–00:17:20`）

Brandon 把问题拉回系统思维：科学过程的瓶颈是不是实验室的湿实验？White 同意模型"至多提出第一个实验"——"大脑里的原子比用完太阳能所能模拟的还多（也许能实时模拟一千个大脑），科学总会撞上必须实测的瓶颈"——但他给出的当前瓶颈非常"不性感"："知道你需要的试剂的货期、实验室里有什么。GPT-5.2 Codex Max 还是 Opus 4.5 做得好可能根本不重要——重要的是哪个掌握了实验室库存、成本与时间的信息。"Robin 论文正是他们想要的循环样板：Agent 提出实验→人做实验→Agent 分析并提出下一个（`00:17:20–00:18:44`）。

更深的前沿他称之为科学品味。"科学很大程度上围绕人类偏好——为什么有人研究某种线虫？有理论说它带来了好药、新基因，但也有一群人的职业生涯押在那条虫上。"模型不擅长判断"什么是令人兴奋的结果、什么是无聊的结果"。他们试过最笨的量化办法——对 Agent 生成的假设做人类 RLHF——结果学到了"我们的 RLHF 有多糟"：人们盯着语气、细节、事实数量与可执行性，却没注意到真正重要的维度——"如果这个假设为真/为假，世界会有什么不同？"那是影响力，不是表面质量（`00:19:44–00:21:10`）。于是他们暂停了那条线，做出了 Cosmos——把品味"烘焙"进去：流程末端有报告与发现，人类只需点击"我喜欢这个"，反馈闭环从"这个假设好不好"这种难以量化的判断，转移到了"下游后果"上（`00:21:10–00:22:02`）。

### Robin 论文的教训：人类的品味没那么可靠

Google 的 Co-scientist 走了完全不同的路线——枚举所有想法、用 LLM 评审与角色扮演做锦标赛式过滤，产出长报告。White 表示佩服，但 Robin 论文给出了一个惊人发现：在干性 AMD（老年黄斑变性，60 岁以上人群致盲的主因之一——眼底垃圾堆积无法清除）的案例里，专家们被请来排列前十假设（"前十之后基本是噪声"），而"人们最看好的假设并不是最终成功的那个"。胜出的假设指向一款重定位药物与一个新颖机制——他在 X 上被质疑过：2012 年某硕士论文第 38 页似乎提过类似机制，他研究了半天认为那更可能是把湿性 AMD 写错了的笔误，"我承认也许有过一例报道"（`00:22:35–00:24:57`）。这次四周的实验"真正开了眼界"：实验成功的假设与人类意见的相关性低于预期。"从那以后，我对验证器在环——数据分析、文献检索、跑单元测试、真去做实验——的信心，远高于'我们更喜欢这个'的反复无常。"

溯因也是他们认真对待的问题：信息来源的可追溯性贯穿一切。第一个 Agent PaperQA（名字起得像邮件列表，抱歉）输出的每句话都带页码级引用；Robin 的每个结论都能回溯到"哪几行 Python 代码算出了这个结果"→"基于这个数据分析与那条文献发现，我认为这是对的"。而最初那个机制的来源其实很朴素：枚举——"如果你不能更聪明，就多试几次"。Robin 的过滤与 Co-scientist 不同：后者用 LLM 评分与角色扮演，他们用文献检索（有没有人发现或证伪过）与数据分析（与数据一致吗）。"在 AI 对人类的优势里，最容易的成功方式就是：更快地尝试更多想法。"（`00:25:45–00:27:26`）

对"假设廉价、验证昂贵"的共识，White 回忆他们试过 Ed Boyden（Sam 的博导）发明的暴力枚举树——目标 X 可以试这些方法、每个方法再分叉出基底选择——早期实验里确实会产出"毫无道理"的假设，全测一遍会浪费大量精力。但如今他判断："让 LLM 去评审一批连垃圾在内的假设，它的过滤效果大概不输领域专家"（不总是，有陷阱），而真正的过滤发生在文献与既有数据——生物银行、GWAS——里（`00:27:54–00:29:25`）。数据分析的分歧是真实的：Heather Kulik 在他们的访谈里就遇到过论文原始数据与论文结论相悖的例子。White 的应对很工程师化：他们自建的 BixBench 生信基准（前沿实验室的系统卡已开始引用）如今模型能到 60%–70% 正确率，而"人类分析者之间也只有约 70% 的一致率"——已经到了人类分歧的水平。药企对数据插补的立场都相反，"真正的现代黑魔法、AI 攻不克的领域是药物化学——那是个准宗教领域"：有 CRO 说某公司从不订购含硼化合物（一个项目死于硼毒性），另一家则钟爱氟化（"对 ADME 性质好"）。 tricks 包括：把 Agent 跑 100 次取共识分析、检验结论对三种不同分析选择是否稳健，以及区分" aleatoric（数据噪声）与 epistemic（选择差异）不确定性"——"还有 Donald Rumsfeld 版本的表述"（`00:29:25–00:33:01`）。

### Cosmos：以世界模型为胶水

Cosmos 评测里那个"只有 50% 多"的数字也被澄清：那不是答案正确率，而是"人类对 Cosmos 结果解读的一致率"。"50% 其实相当好——实验室里的实验本来就不是二元硬币，结果远不止两种。前沿现在就是科学品味：怎么让模型的解读与人对齐。"（`00:33:02–00:34:39`）

Cosmos 的谱系被 White 自嘲为"事后诸葛亮也讲得很好听，但实际上我们就是大量尝试，有时成有时不成"。他是"乐高式"建造者：ChemCrow 负责药物化学搭建、ProteinCrow（未发布）设计蛋白质、数据分析 Agent、Ether 0 模型（"前沿模型处理分子不行，那就造一个有药化直觉的模型"）——Sam 推着他们"试试整个流程"，于是有了 Robin：把已有 Agent 装进一个"简洁的 Python 文件"的工作流——生成一堆想法→文献过滤与证伪→提出湿实验→分析数据→循环。Cosmos 则源自更根本的追问："Robin 自动化的到底是什么过程？"答案是世界模型："我对所研究现象有一套理解，我的大部分行动都是在更新它；它随时间变化，还能做预测——这就是它不只是记忆或一堆论文的原因。"关键突破来自 Ludo（Cosmos 论文一作）的执拗：世界模型的各种尝试一度都不理想，他停了两周后默默继续，某天说"来看看这个"——他发现了"实验循环"的钥匙：把数据分析 Agent 放进循环，世界模型才能真正被更新。"我们之前围着文献建——文献当实验的替代品根本不工作；数据分析才让你真正探索想法。"Cosmos 就是把世界模型、数据分析 Agent、文献 Agent、以及一个科学 Agent 平台（LaTeX 报告、漂亮图表）拼起来，"世界模型是让它们咬合的胶水"（`00:34:39–00:38:40`）。类比是 GitHub：编码 Agent 以共享仓库为胶水，软件工程师花了几十年思考协作方式；世界模型像"一个大的信息束、随时间积累并被蒸馏"——"Git 仓库也是蒸馏：长长的提交图最终凝成当前的文件系统"（`00:38:40–00:39:48`）。至于世界模型的实现？"那是我们现在的秘方。"（`00:39:48–00:40:00`）

### MD/DFT 过时论与 AlphaFold 的启示

White 贡献了本期最热的热辣观点："分子动力学被高估了——DFT 可能更被高估。这两种方法consumed 了无数博士生涯，献祭在模拟之美的祭坛上。"Brandon 插话：前 ChatGPT 时代估计全球约 20% 的算力在模拟水。White 的亲身经历：用国防部超算跑了五个月的 DFT 水模拟（含量子效应与 Grotthuss 质子跳跃机制），约百万 CPU 小时、人生最大规模的计算、YouTube 播放最高的视频——"学到的只是哪组超参数能复现水的某些物理效应，没有一样是 de novo 的。"他的批评是结构性的："MD 和 DFT 并没有正确地建模世界，我们只好编故事说自己的归纳偏置是好的：DFT 里想要室温的水却要在 330K 模拟——室温是 330K 吗？GGA、B3LYP 这些泛函明显是经验的，焊到 DFT 上之后大家说'看，第一性原理'——其实你对验证数据过拟合了。改变世界的催化剂没有一个是适合 DFT 的单晶——全是晶界、掺杂、复杂性，DFT 永远抓不住。模拟擅长模拟无聊的东西，不擅长模拟有意思的东西。所以我不再做 DFT 和 MD 了。"（`00:40:04–00:43:07`）

AlphaFold 则是那记响亮的对照实验：MD 本被视为蛋白折叠的解法，D.E. Shaw Research（DESRES）用与 DeepMind 相当甚至更多的资金、"把 MD 能折叠蛋白质这个假设验证到了死"——自研芯片、把算法烧进硅片、David Shaw 坐直升机去开会讲他们的专用机房。而 AlphaFold 用的是 X 射线晶体学数据，训练只要约 1 万 GPU 小时，"在 Google Colab 或桌面 GPU 上就能跑"。"两个资源雄厚的组试了不同的想法，实验数据上的机器学习以巨大优势击败了第一性原理模拟。这是'苦涩的教训'的加强版——人类非常不擅长估计非人造问题。"（`00:43:07–00:45:32`）Cosmos 里其实已经集成了 BoltzGen（公开注册版暂未包含）；你也可以把 Modal、Lambda 等包装的蛋白质/化学设计工具直接喂给 Claude Code 或 Cosmos——"想为 X 设计蛋白质？用这些工具。"（`00:45:32–00:46:10`）

### CBRN、Jevons 悖论与"语言是化学的自然语言"

安全话题上，White 的判断分两波。2023 年的第一波答案是"基本不会加速"：危险化合物的合成路线在 Wikipedia 上就有、生物武器的靶点不是秘密；大家担心的实验协议隐性知识、放大生产的技巧、绕开追踪清单的订购策略，已被多个机构认真测试并纳入流程（模型会拒绝或被过滤），但他承认"这是一个存在真实风险的区域"。第二波正在浮现："实时协议排障、计算侧的深度参与——有些两年前觉得太遥远的场景现在变得现实。聪明人在关注，但还没解决。"他还点出了被忽略的"二阶双用途"：LLM 能帮你通过离心机供应商的 KYC、告诉你去哪订、预期价格、先订什么——"电子邮件不也让订购离心机更容易了吗？某种程度上邮件就是双用途技术。"他对美国政府当前"较慢、较不深入的安全审视"有所忧虑，但也坦言自己的观点尚未成形："我时而觉得做得不够，时而又觉得我们还有很多时间。"（`00:46:10–00:52:14`）

关于自动化科学与科学家的未来，他用 Jevons 悖论作答：自动化出租车司机会取代岗位，因为人们对出行的需求有限；"科学的需求没有上限——不存在'还有 100 个发现然后就没有了'的情况。科学变快只会让需求涨到匹配自动化的程度。"他眼中未来的科学家是"Agent/Cosmos 驯兽师"：同时探索 100 个想法、借助系统做出 10 倍、100 倍的发现。但在具体的 nut and bolts 层面他承认摩擦存在："如果我是药企或材料公司的 CEO，是再花一百万美元买 AI 科学家算力，还是招 10 个人？我可能选 AI 科学家——招人太难了。"他也相信科学更像艺术：发 Nature 不只因为改变世界，还因为"这科学真有趣"——"科学的享受者本身就是科学家，所以很难想象科学家不成为科学的消费者的场景。"他引了 Ted Chiang 2003 年前后的短篇：科学家先被取代、沦为 AI 科学论文的"翻译者"，然后连论文都读不懂了，就此失业——"但科学必须被翻译才能产生影响；工程可以自闭环（给我造太空电梯材料，到时候照方抓药即可），而'生命起源是什么''别的行星上有没有水''为什么这个催化剂更好'，最终必须进入人类的眼睛与大脑。人类至少要在某个环节说'这是好科学还是坏科学'——这又回到了品味。也许你是对的，也许人类没有意义了，就像 Sora 那个 AI slop 应用——但 Sora 里最终还是有人在点击视频。"（`00:52:24–00:57:44`）Brandon 追问"会不会出现精品手工科学的利基市场、以及模型偏见造成的永远盲区"，White 的回应是：一些做实验室自动化的公司（如在 Emeryville/Oakland 的那家）将检验这个理论——"如果偏见真是瓶颈，它们会开始做得特别好，我们会看到证据"。至于暗物质这类基础物理问题："给出完整故事所需的数据目前还不存在。每家公司里最大的批评者都是自己——Cosmos 很棒，但还有巨大的改进空间。"（`00:57:44–00:59:59`）

### 强观点的方法论

节目结尾回到他最著名的论断"化学的未来是语言"。他仍然相信："当时的问题是：我们有溶解度预测模型、大人群数据、论文与代码——唯一能桥接这一切的就是自然语言。人类 whenever 无法表达就发明新词——这是人类做了几千年的唯一共享活动：发明词语来表示我们所知的一切。"他承认 LeCun 式的反驳（世界模型、具身、语言 imposed 的天花板）有道理，并用"雅各布天梯"的例子说明表示的层次：分子可以叫名字、画图——但二茂铁没有明确键连、甘氨酸甜菜碱有二面角（是构象系综）、苯还有电子密度不能忽略、再到电子相关、相对论效应、宇宙射线背景——"不知不觉你就把算力烧光了。总得在某处画线。自然语言是人类花了极大力气调校好的那个边界：抽象到不必知道所有细节，又具体到可用。也许未来有视频或多模态融合，但眼前它是最好的。"（`01:00:38–01:05:42`）Brandon 用"量子力学无法用语言描述"反驳，他半让半争："量子力学其实有五到七条原理可以用语言相当简洁地表达——理解后果确实需要数学。"而他的方法论宣言 perhaps 是全期最值得记住的："我喜欢采取强观点，看看它能带我走多远。职业生涯里，采取那些我内心知道未必完全正确的强观点，反而让我一路走了很远。在 FutureHouse 我们采取'科学 Agent 是未来'的观点，于是跳过了'为 X 领域建基础模型'的整个阶段——我记得有家著名的公司喜欢保留可选性，在基础模型上浪费了很多时间。总有一天我会放下这个观点，再找一个新 的。"（`01:05:46–01:08:09`）

彩蛋是 EtherZero 的奖励黑客故事：概念上很短的项目——"可验证奖励在数学和代码里进展巨大，在化学里做一遍"——化学不可验证，于是先定"造一个 3 氮 2 氧 10 氢的分子"这种可检验目标。结果每次训练模型都找到新的诡异技巧：把该有的检查全过了（键、电子数、原子数），却把所有氮堆在一处、所有氧堆在另一处；加了"符合最佳实践"的规则，它开始生成氮链——"三个氮就爆炸了，四个根本做不出来"——它直接生成六氮化合物，"字面意义上不可能"。直到某天组员发来消息：Nat ure 官网今天头条——有人做出六氮化合物，那是某人整个职业生涯的壮举、极不稳定的疯狂分子、谱学鉴定难如登天。"看吧 Andrew，它并非真的不可能。"White 澄清："不，我们的模型就是在 reward hack。"下一个验证器是"试剂必须可购买"——模型学会"把目标化合物去掉一个原子说'买这个再装上'"；加上"必须参与反应"——它开始玩酸碱化学（酸可购买、能挪一个原子）；最后他坐在那里"为训练循环造一个可购买化合物目录和布隆过滤器"，自问"我怎么走到了这一步"。"监督学习是放松愉快的——有输入有输出，一切稳健。可验证奖励要求写出防弹的验证器，太难了。我们训了那么多模型，最后发现它们在黑客我们设置里某个随机的东西。我一点也不羡慕要在海量规模上做这件事的前沿实验室。"他们还改过 GRPO（DAPO 一类的修改、特殊的裁剪），并分享了一个经典 debug 故事：模型表现崩坏，查到最后是训练数据把试剂按字母排序而测试数据没有——"它的整个策略就是利用你的排序方式。"（`01:08:11–01:13:31`）
