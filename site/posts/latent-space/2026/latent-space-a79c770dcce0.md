## 速读

Modal CEO Erik Bernhardsson（Spotify 推荐系统与 Luigi 工作流框架的作者、Better.com 前 CTO）时隔两年再访 Latent Space，公司规模已较上次增长约 50 倍。本期最有信息量的三段：AI 基础设施公司如今要对接约 25 朵云、组建专职采购台与十人裸金属工程团队才能拿到足够 GPU；稳定扩散（而非 ChatGPT）才是 Modal 的第一个杀手级应用；以及每个新技术时代都要重造工具的论点——旧世代的 Kubernetes 与 Docker 不是为昂贵 GPU 与秒级扩缩而设计的。（`00:10:30–00:12:08`）适合 AI 基础设施工程师与关注算力经济学的从业者。

## 主题正文

### 从 Spotify 到 Modal：Luigi、Better.com 与「基础设施太烂」

Erik 的职业底色是数据密集系统：2008 年加入 Spotify，七年里从零搭建第一版音乐推荐系统，上线了 Related Artists 与 Discover Weekly，做了大量矩阵分解与计算密集型工作；后来发布的开源工作流框架 Luigi 与 Airflow、Prefect 同属一类。（`00:01:32–00:05:07`）随后在 Better.com 做了五年 CTO，把技术团队从两三人带到四百人，学了管理与开发者生产力，最终回到心中最近的「基础设施与 AI」。（`00:02:20–00:03:38`）

2021 年离开 Better 后的探索并不顺利：网页抓取工具没做起来，回到工作流编排方向时意识到核心难题其实是「执行算力」而非「编排算力」，于是把后者搁置——这个搁置最终变成了 Modal：让在云端运行代码（GPU 代码、AI/机器学习、数据任务）变得极其容易。（`00:04:53–00:06:08`）早期的关键认知是必须深入底层：自研文件系统、自研容器运行时。（`00:06:17–00:06:36`）

### 稳定扩散才是第一个杀手级应用

ChatGPT 并不是 Modal 的转折点——同一时期发布的稳定扩散（Stable Diffusion）才是。当时 Modal 只有四五个人，突然大量用户涌来要跑稳定扩散，让他们意识到生成式 AI 推理正是自家平台的最佳用例。（`00:06:36–00:07:04`）增长引擎是 Erik 自嘲的「创始人主导营销」：强迫性发推、写长博客谈云的未来，「我擅长的是 shit posting 和永远在线」。（`00:07:04–00:07:34`）

财务轨迹非常具体：自资助运营到 2022 年初才融种子轮（Akshay 于 2021 年 8 月加入任 CTO 联合创始人）；2022 年 11 月月收入约 100 美元，次月 2000 美元，2023 年 1 月跳到 3 万美元——「胸口的大石头终于落地」。当时纽约一家叫 Mage 的稳定扩散公司占其收入的八九成，年底 Suno 成为重要客户，如今收入已充分多元化。（`00:07:44–00:09:38`）早期用户用 Modal 跑的多是偏底层的自定义工作流——Modal 的可塑性恰好也适配了生产负载：自动扩缩本质上是同一个问题。（`00:09:48–00:10:21`）

### 「每代技术都要重造工具」

Erik 的核心论点：每个新技术时代都会撞上旧工具的天花板——云计算时代发明了 Kubernetes 与 Docker；生成式 AI 可以建在旧工具上，但那些技术是为「平稳的后端负载、低利用率、廉价的 CPU」设计的，而新世界是昂贵的 GPU、容量与利用率管理、大模型要经网络加载进 GPU——旧工具完全不适配。（`00:10:30–00:11:50`）因此 Modal 自研了文件系统、CPU/GPU 快照、自动扩缩器、调度器与整套容量管理工具。「在旧东西上包一层做不了新东西，你得从头开始一部分。」（`00:12:08–00:12:29`）

早期另一个后果深远的决定是多区域：把容量管理视为「全球一个大池子」而非每区域独立集群。（`00:12:35–00:13:02`）Modal 历史上也经历过扩容瓶颈与故障，近期可用性已达到四五个九。（`00:13:02–00:13:25`）

### 25 朵云、采购台与买租之辩

容量获取在两年间发生了质变：早期几乎全部来自超大规模云的竞价与按需容量（先 AWS，后 GCP、Azure），又因想要 A10 与 H100 而较早从 Oracle 租赁并拿到优惠价；直到去年底，大部分容量仍是竞价或一年期预留。（`00:13:33–00:14:13`）如今为了拿到所需容量，Modal 对接约 25 朵云，常常要签三年以上的长约并预付可观的款项——过去六到九个月被迫重构整个容量获取体系：四人专职采购台全天打电话谈价、验货，外加十人工程团队管理全球裸金属、处理网络故障、坏盘与「GPU 掉总线」。（`00:14:33–00:15:33`）

买还是租的权衡他并不教条：租有资本效率优势；买则有运营复杂度（供应商、电力、线缆）与融资复杂度（股权融资太稀释、债务融资需要锁定的长期收入来付利息）。看经济性、看运营复杂度、看风险，「一切都在桌面上」。（`00:15:44–00:16:47`）他观察到 neocloud 已是「非常成熟的金融工程公司」，AI 投资开始占到美国 GDP 的数个百分点，利率上行——Modal 宁可保持轻资产软件公司，不为持有重资产分心，但为了 2027 年的容量，一切选项都在评估中。（`00:16:56–00:17:58`）

对「供给会长期紧张」的说法他部分不同意：NVIDIA 每月交付数十万片 Blackwell，只要出高价就能买到容量——市场并未被完全垄断；同时他也承认当前处于「硬件价格上涨」的反常期——长期而言硬件价格总是下跌，这个状态可能持续六个月也可能三十六个月。（`00:17:58–00:19:01`）短缺时期的稀缺租金主要流向 NVIDIA 与 neocloud；而他更担心的反而是价格崩塌——那对锁定了大量供给的玩家是坏事，「在高点买入」的风险真实存在。（`00:19:25–00:20:18`）

### 沙箱：从附属功能到第二产品

Modal 的两大产品是 Modal 本体与 2023 年上线的 Modal Sandboxes。前者从「极易部署与扩缩的 serverless 函数」出发，恰好适配推理、微调与批处理。（`00:32:07–00:32:33`）沙箱的起点是观察到大量用户在用 LLM 输出代码——需要安全隔离环境来执行；Modal 已有 gVisor 等隔离原语，于是顺手做了出来。（`00:33:23–00:33:51`）此后增长惊人：vibe coding 公司、Ramp 用 Modal 跑后台 Agent、多家 neolab 的训练评估负载涌入，沙箱正式成为公司第二产品。（`00:34:53–00:35:32`）他一直想做多产品厂商，「直到 Sandboxes 才在实践中成立」。（`00:35:32–00:35:52`）

为 Agent 场景的更新包括：支持虚拟机以获得完整 Linux 兼容性、更具交互性的原语，以及快照能力——他的愿景是让长跑 Agent 拥有快速的「唤醒-休眠」周期：类似 Claude Code 的流程如果能拆成一千个沙盒并行执行，「为什么要线性地跑」。（`00:41:24–00:45:25`）Anthropic 的 managed agents 也在使用 Modal 沙箱——Agent 跑在沙箱里、模型服务在 Anthropic 侧，是理性互补的分工。（`00:46:48–00:47:55`）

对「agentic」一词他有复杂的感受：模型本身不是产品，真正的护城河是「通用、经受过实战检验的基础构件」。（`00:37:03–00:37:34`）在研的新方向包括训练（被大型玩家忽视的中小型训练与后训练强化学习细分市场）与语音模型带来的新需求。（`00:36:12–00:36:52`）
