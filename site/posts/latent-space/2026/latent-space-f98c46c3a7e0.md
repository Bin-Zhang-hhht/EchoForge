## 速读

Abridge 2018 年就起步做医患对话的 ambient 记录，比 ChatGPT 早了四年；如今号称覆盖 250 家大型医疗系统、每年 8000 万以上的医患对话，正从环境式文档扩展成"临床智能层"。产品负责人 Janie Lee 与临床决策支持负责人 Chai Asawa 在这场与 Redpoint 的联动播客里讲清了这套系统的全部难点。

最值得带走的三点：医疗告警九成被忽略，解法是"像空调"——平时无感、只在风险高且必须立刻干预时出现，比如让医生在病人离场前补齐 prior auth 的两个条件、当场锁定批准；EHR 可以被当作 Agent 的文件系统，"每个 Agent 底层都是编码 Agent"；以及"AI slop 就是没有上下文的 AI"——编辑、偏好与记忆构成数据飞轮。

## 主题正文

### 三幕剧：省时间、省钱、救命

Janie 把公司历程讲成三幕。第一幕是省时间：临床医生每周花 10–20 小时写文档，下了班回家穿睡衣补病历——业内叫"pajama time"；他们的 Slack"Love Stories"频道里塞满了"终于能准点回去陪孩子吃晚饭"和"我们不再闹离婚了"式留言。第二三幕是帮医疗系统省钱、赚钱、救命：医疗系统运营利润率处于历史低位，而他们的软件每周在病人进诊室前后被打开数百万次，这个位置给了临床决策支持等产品巨大的机会（`00:02:26–00:04:04`）。底层判断是：医患对话可能是医疗里最重要的工作流——GDP 的 20% 花在医疗上，而理赔、支付、诊断、治疗几乎都是那段对话的衍生品（`00:00:42–00:02:01`）。

### Context is king：healthcare 版的 Glean

Chai 从 Glean 跳槽而来，他的框架是"这是 healthcare-coded 的 Glean"：两家公司的共同洞察是模型已经很强，context 才是让它们干活的东西。差异同样关键：医疗的下界风险是致命的（开病人过敏的药），这直接塑造了评估策略；垂直场景的方差虽然存在（专科、医院系统）但更窄，让你能更专注地打磨新产品；以及他们从第一天就是 ambient、始终在听的模态——"最好的 AI 是无感的 AI，你看不到屏幕，它一直在帮你、主动帮你"，是每个黑客松都出现过的 Jarvis 愿景（`00:04:33–00:06:57`）。随之而来的产品哲学问题是何时打断：医疗告警臭名昭著，九成以上被忽略。Janie 的表述是"我们想让它像空调"——在后台默默把事情变好，只有当临床风险高、此刻不干预就晚时才出现；更结构性的解法是从反应式告警转向主动情报：与其在医生与病人的敏感对话中弹五次窗，不如在医生进诊室前把该讨论的事项准备好（`00:06:57–00:08:00`）。

Prior authorization 是这套哲学的样板戏。典型体验：膝盖痛，医生开了 MRI，四周后保险公司来电说没批，回来重新弄。Abridge 的做法是趁病人还在诊室，安静地提示医生："在 Sean 走之前，问他做过物理治疗没有、疼痛是否超过六周——他那个 Aetna 加州计划要求六个条件，我们已经用上下文确认了四个，你补齐这两个，MRI 就能在你离开前批下来。"把通常数周的流程压缩到实时，省时间、省钱、救生命三项全占（`00:08:00–00:10:23`）。这件事的难点也定义了护城河：要接 EHR 拿全部病人上下文、要收集按州变化的付款人政策（有些活在网页上、有些活在 50 页的非结构化 PDF 里），还要扛得住极高的准确率门槛——她在 Opendoor 做定价模型时学到"一个离群值抹掉三十单的利润"。Chai 补充了 AI 视角：质量问题本质是告警信噪比，而真正的机会是"用 AI 降低世界的延迟"——护理延迟被压缩，且避免了保险公司与提供商的 AI 在事后互相打架的名场面（`00:10:23–00:12:36`）。

### 模型策略：对话是医疗的 trace 日志

被问及最难的 AI 问题，Chai 的答案是三角权衡：质量、延迟、成本通常可以逐个优化，但 prior auth 要求在对话进行中实时给出高质量指引且不烧钱——"很多人还没意识到这三个 KPI 要同时满足"。解法是 clever engineering：把政策建模成某种中间表示让问题可处理，且帕累托前沿每个月都在变（`00:17:11–00:18:26`）。模型策略上他们是"模型星座"：第三方模型的趋势要预判（编码 Agent 的训练投入在加大、消费级模型因海量医疗问句而在权重里编码医疗知识——这对他们是顺风），而自研模型的护城河来自专有数据：约 8000 万条医疗对话（如今接近上亿），CEO 称之为产品的"exhaust"——它是病人与提供者之间调试发生的 trace，可以用来以更低成本更快地训练转写、分离说话人与 note 生成模型（`00:18:26–00:21:07`）。另一个被广泛验证的判断："几乎每个 Agent 底层都是编码 Agent"——EHR 本质上就是医疗的文件系统，装着远超上下文窗口的信息，模型越会像操作文件系统那样操作它，产品能力越直接受益（`00:21:07–00:22:09`）。实时性上今天仍是批次处理，原型已能按对话中的正确时机触发 Agent 工作流；他们刻意不做语音进语音出——诊室里"病人和医生都不想要第三个声音"，文本输出、 clinicians 保持对病人的专注（`00:22:35–00:24:03`）。

### 个性化三层、AI slop 与评估栈

个性化被拆成三层：个人层面（笔记是医生工作方式的深度映照，有人要 bullet 不要段落、要两个空格，"我拒绝用这个工具"式的反馈真实存在——难点是别让风格偏好侵蚀准确性）；专科层面（心内科与皮肤科的 note 结构、什么算完整、什么算可计费完全不同，CEO 本人是仍在每月 round 的执业心内科医生，所以心内是"绝对不能搞砸"的样本）；医疗系统层面（医院数十年打磨的最佳实践指南想直接嵌入产品——这既是需求也是护城河）（`00:24:03–00:27:23`）。Chai 给"AI slop"下的定义流传度会很高："AI slop 就是没有上下文的 AI"——临床文档同 AI 写作一样，不像你自己的东西就是 slop；而他们握有全部上下文，加上医生对产出的每一次编辑和记忆系统（记忆子 Agent 在后台提炼值得长期记住的偏好、后台任务像睡眠一样整理），构成越用越准的数据飞轮（`00:27:23–00:28:24`）。

评估栈的完整度是这场访谈对 AI 从业者最有参考价值的部分：每个新产品从第一天就问"好是什么样子"（临床安全是 table stakes，再往下是风格、完整性、可计费性）；流程从内部临床医生的 LFD（look at the fing data——内部黑话， JANIE 入职三天才敢问全称）首审，到跨维度构建 LLM judges 并用内外部标注数据校准，再到按风险等级引入第三方评估，大变更上线前全部走完。进化方向是把月级的流程压到天级，而"很大一部分不是 ML 问题，是运营问题"——提前规划容量、搞清哪个第三方擅长哪个用例。专科级校准是最耗 cycle 的部分：皮肤科的好 note 长什么样，需要内部外部、线上线下反复标定（`00:30:40–00:34:09`）。发布策略类比 Waymo 的"世界上最有经验的司机"：尽快接触现实但渐进发布，离线评估集和在线反馈随发布线性增长。客户节奏也被他们改写了——医疗系统的发布周期通常是季度甚至半年一版，Abridge 把大客户带进了月度节奏，还有相当一批客户主动要求 pre-GA 一起磨产品；那句内部格言是"信任以滴获得、以桶失去"（`00:34:35–00:36:45`）。

### 隐私、规模与"80/20 在这里不管用"

隐私侧的回答干净利落：用于学习与评估的现实数据必须先去标识化，他们自研了从临床转写中移除 PHI 的模型——但要先证明这个模型本身可靠，因为那是"概率系统叠概率系统"；匿名化是单向的、没有主密钥，客户合同还规定了 PHI 的访问权与保留期限。Jacob 提到的患者态度也很真实：癌症患者被问是否愿意让系统学习自己的经历，回答是"全都拿去，请"（`00:36:45–00:39:21`）。规模侧，1 亿次对话量级把成本变成了架构问题——原型阶段可以随便烧最贵的模型，到了这个量级就要靠专有数据做 post-training，在"预期第三方模型不会优化的区域"做效率最大化；自然的轨迹是 0→1 阶段谈优化没有意义，1→100 阶段零到一积攒的数据正好派上用场（`00:39:46–00:41:36`）。展望上，Janie 的愿景是同一段对话服务所有干系人——医生的文档、病人的"刚才发生了什么"、付款人的适当性判断、药企的临床试验候选匹配——把如今彼此割裂的昂贵系统收敛到一个平台（`00:41:53–00:43:15`）。EHR 关系被定位成深度共生而非对抗：拉推数据是 table stakes，临床医生要省每一次点击（"新功能多加两次点击，他们就不用了"），而付款人对接、试验匹配这些是 EHR 领域之外的临床智能层（`00:44:10–00:46:37`）。

监管的意外是顺风：政府推动互操作性，FDA 在今年一月更新了临床决策支持的指导思路，比 2022 年那版前瞻得多——"AI 与医疗监管同时处于特殊时刻"。Janie 的反直觉判断是本期题眼：正因为医疗 stakes 高，80/20 在这里不管用，零错误的 eval、低容忍的多步工作流"必须被解决否则无法发布"，所以一些最难的 AI 问题会先在医疗被解决；传统上"医疗公司技术含量不高"的污名，在这些又难又有趣的问题面前站不住（`00:47:02–00:48:48`）。长尾质量的组织解法是"clinician scientist"角色——有 MD 背景又 deeply technical 的人（内部领导戏称 mutants）嵌进产品与评估团队，瞬间抬高所有产出物的标准；评估规模（几百条还是几千条离线样本）则被他们尽量从艺术变成科学（`00:50:32–00:53:02`）。收尾的两段很有人味：Chai 从 Glean 学到的持久经验是"质量改变一切游戏"；Janie 则公开认错——"PRDs 已死、原型为王"这句话她收回了一半，在复杂度这么高的产品里，原型捕捉不了数据边界、战略必要性、护城河与实施成本，"在满是噪声的世界里，清晰的书面表达比任何时候都重要"——写法可以变（现在活在 markdown 里给团队和系统当上下文），但先想清楚"为什么该由我们做这件事"不能省；她把这叫 go slow to go fast：把 45 天 20 个触点的 prior auth 收敛成一个流程，是她职业生涯里最快的产品构建（`00:57:34–01:02:30`）。基础设施侧的持久判断来自 Chai：为人类协作造的东西——Kafka、Temporal、sockets、CRDT——会持续有效，只是要扛住千倍于人类的 Agent 规模（`00:55:40–00:57:03`）。至于内部工具，答案毫不意外：全公司建立在 Claude Code 上，工程师屏幕上同时跑着六个 Claude（`01:03:11–01:04:00`）。
