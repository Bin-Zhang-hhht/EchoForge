# 推荐系统到底该优化什么：从点击之外的目标到 LLM 的边界

## 速读

这是 Data Skeptic 推荐系统季终三部分的第二期：主持人 Kyle 把整季访谈串成一个核心问题——推荐系统到底应该优化什么。他的起点是对 Netflix Prize 的批评：以 RMSE 衡量的评分预测只是"想看的下一部片"的代理指标，必要而不充分（00:00:32）。现实中的平台大多在优化参与度，而参与度分不清享受与愤怒，于是有了 doom scrolling。全期借多位受访者之口给出更丰富的目标清单：多样性要按证据成比例、公平要覆盖创作者生计、可持续目标可以引导用户错峰旅行。技术底座是把品味变成向量（embedding）与两阶段架构，而 LLM 带来对话式推荐的同时也带来"流利的幻觉"——Air Canada 聊天机器人案是本期的警示故事。

适合做推荐系统或增长的人听全文；最值得听的是第 10–12 分钟关于"修正不公平反而提升整体性能"的反直觉结果。

## 主题正文

### 优化的错位：评分、点击都不是终点

主持人对 Netflix Prize 的批评是全期的锚点：赛题的 ground truth 是用户对已看影片的评分，而系统真正想预测的是"你接下来最想看什么"，两者相关但不相同——RMSE 是必要不充分条件（00:00:32–00:01:13）。现实走了另一条路：大多数存活的推荐系统优化的是参与度——点击、观看时长、平台停留（00:01:52–00:02:11）。但参与度无法区分"喜欢"和"愤怒"。受访者 Gregor Durner 指出，网络骂战对推荐系统而言和喜欢一首新歌没有区别：都是互动、都是停留（00:02:34–00:03:03）。Andrea Ayana 补充了反馈回路：系统为最大化点击而推荐与用户已消费内容相似的东西，用户看什么，明天的训练数据就是什么，过滤气泡由此固化（00:03:34–00:04:19）。Hui Li 的主动探测实验则显示，点赞行为会把整个信息流的情绪推向那个方向——不只推荐"悲伤的猫"，而是让整体内容变悲伤（00:04:21–00:05:12）。

### 目标变复杂：利益相关者不止用户一方

主持人列举的"奇怪目标"其实各有严肃的论证。Vaclav Blahut 解释流行度偏差：模型会放大"富者愈富"，热门内容被推荐得更多，即便它未必更相关（00:06:22–00:07:04）。Anas Bahai 提醒推荐系统是多方的：服务提供者（providers）、消费者和平台都是利益相关者，文献里常常只把消费者当"用户"（00:07:29–00:08:16）。Rebecca Salganek 把这一点推到生计层面：独立音乐人的收入直接取决于算法给不给出曝光，算法的推荐决定"他们能否继续做音乐"（00:08:36–00:09:14）。

本期最反直觉的结果来自 David Luu：小众用户数据更少、偏好更复杂，模型天然容易在这些群体上欠佳；但他的 item-weighted PCA 实验显示，修正这种不公平机制不仅能保住性能，某些情况下反而提升性能——因为"学好 embedding 对所有人都有利"，坏的表征同时伤害冷门和热门艺人（00:10:26–00:11:43）。这颠覆了"提升公平必然牺牲性能"的主流叙事。另外两段旁支也有意思：Spotify 的编辑用"适合在车里唱的歌"这种机器难以从数据中挖出的概念做人工策展（00:12:35–00:13:20）；Kat Federova 用博弈论研究算法抵抗运动，发现集体"假装互动"的抗议行为按某些指标反而改善了平台推荐（00:14:27–00:15:12）。

### 什么才是好目标：按证据成比例的多样性与可持续

Andrea Ayana 给出对多样性的精确化：真多样性不是给政治光谱每边都推荐一点以示平衡，而是按证据比例推荐——阴谋论不应与科学共识获得同样的权重（00:15:36–00:16:20）。Ashmi Banerjee 的可持续旅游推荐是同一个思想的具体化：用户喜欢艺术与建筑、七月出行，默认答案巴黎、罗马会加剧过度旅游；更好的推荐是特征相似而游客更少的目的地，或者建议改到 11 月、12 月的肩季去巴黎（00:16:27–00:17:54）。主持人总结：这些人都在要求推荐器优化比点击更丰富的目标——多样性、公平、创作者生计、探索发现（00:17:55–00:18:09）。

### 表征时代：embedding、冷启动与两阶段架构

现代推荐系统的主线是把混乱的人类品味变成机器能处理的向量：从 Netflix Prize 的矩阵分解到今天的 embedding，变化的本质是从手工特征到学习特征——不只看评分，还有简介文本、影评、海报像素、预告片配乐的频谱（00:18:12–00:19:36）。Irvin Dervishah 研究解耦表征：推荐 T 恤时，尺码和价格应是不变的独立分量，改变一个不应影响另一个，这关系到可解释性（00:20:14–00:21:07）。冷启动没有完全消失，Boya Zhu 的框架是把最初几次推荐当实验：好的先验帮你缩小探索范围，这就是 explore/exploit 的多臂老虎机权衡，而这个旋钮拧得太保守，冷启动、流行度偏差、过滤气泡三个问题都会出现（00:21:07–00:22:40）。她的实验还表明，更多学习可以缓解多数组与少数组之间的收益差距，让算法对两个群体更公平（00:23:13）。架构上，向量只解决"什么相似"，服务十亿用户靠两阶段设计：检索阶段用双塔模型廉价地从数千万条目里取几百个候选，排序阶段再花真正的算力精排（00:23:31–00:24:19）。

### LLM 时代：会对话，也会流利地撒谎

LLM 打破了"给目录打分"的框架：它不需要对目录排序，可以直接用自然语言理解需求，推荐从排序变成对话，还能连接数据集之外的世界知识（00:24:53–00:25:33）。但代价是幻觉，而且幻觉的危险在于"看起来自然"——在医疗等敏感场景，错误的药物建议不会显得错误（00:26:24–00:26:49）。主持人举了真实案例：2024 年 Air Canada 聊天机器人向丧亲乘客虚构了并不存在的丧亲折扣，航空公司还辩称聊天机器人是"独立法人"，仲裁庭不认可并判其担责——如果推荐器会说话，它就会流利地撒谎（00:26:52–00:27:20）。可行的缓解是把模型锚定到可信事实源：通过 MCP 或 RAG 查询真实产品目录，模型负责推理，事实必须来自可信来源（00:27:26–00:27:41）。Fouyan Lei Yu 的立场是不必整体替换成熟管线，让 LLM 做控制器去调度现有方法，这一思路同样适用于医疗、金融等预测任务（00:27:54–00:29:04）。收尾的反向提醒来自 Hannes Rosenberg：他写过多本书，但从不让 LLM 代笔创作——有些事语言模型就是不该替你做（00:29:24–00:30:11）。
